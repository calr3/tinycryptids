# A Turing machine for the Erdős–Moser equation

**Current best: `machines/erdosmoser_71.txt`, a 71-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff the
Erdős–Moser conjecture is false**, i.e. iff `1^k + 2^k + … + (m−1)^k = m^k` has a solution with
`k ≥ 2` (for `k = 1` there is `1 + 2 = 3`). Lean proves this (`TM.ErdosMoser.M71.halts_iff`):

    Halts M71.delta2 M71.start2 ↔ ∃ k m, 2 ≤ k ∧ 1 ≤ m ∧ powSum m k = m ^ k

where `powSum m k = 0^k + 1^k + … + (m−1)^k` (`../lean/TinyCryptids/Defs.lean`).
`RECORDS.md` lists the machines, and `PROOF.md` walks through the proof in plain words.

The 71-state machine is obtained in two stages:

1. `erdosmoser.txt` is the readable **117-state design**, generated by `build.py`. The Lean
   proof is written for this machine (`TM.ErdosMoser.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition the
   run uses (an exact SAT search; `kissat404` and `cadical195`). `gen_reduced_lean.py` carries
   the theorem over, and `machines/erdosmoser_71_annotated.txt` is the same machine with each
   state named after its roles in the design.

## The search

    for s = 4, 5, 6, …:                       (the pairs along the diagonals k + m = s)
        for k = 2 … s − 1, m = s − k:
            A := 0
            for β = 1 … m − 1:  A := A + β^k
            if A = m^k: HALT

The powers are those of `../fermat/` (`R := 1`, then `k` rounds of `R := R·β`: copy R `β − 1`
times onto Q and merge), and so are adding R into A and the zig-zag compare.

## How it works

The tape, left to right (blocks of 1s, separators `0 0`, a hole is a single 0):

    K 00 M 00 A 00 R 00 Q

* **K** has `k + 2` cells and a cursor, the exponent counter, on cells `1 … k + 1`. On its last
  cell the cursor sits next to the separator (as in `../beal/`). Between powers it rests on
  cell 1 (the anchor), and a power starts with an exponent step.
* **M** has `m + 3` cells and a **marker** hole on cell `p` (`1 ≤ p ≤ m`). The cells right of
  the marker are Fermat's base block, with the marker playing the separator: the base is
  `β = m + 1 − p`, and the base cursor runs over cells `p + 2 … m + 2`. The last of these is next
  to the separator. A round starts with no base hole: the cursor is then on cell `p + 2`.
* **A** has `1 + Σ` cells, **R** (the running power, its hole the copy cursor) `r + 2`, **Q** is
  scratch.

**One pair.** The marker starts on cell `m` (base 1). After each power, if the marker is on a
cell `p ≥ 2`, it moves one cell left (base `β + 1`), R is added into A, and `R = 1 0 1` is pushed
again from the end of the merged block. If the marker is on cell 1 (`R = m^k`), it is filled,
R's hole is filled and its first cell erased (`m^k + 1` cells against A's `1 + Σ`), and a zig-zag
erases one cell of A and one of R in turn: the machine **halts** if both run out together.

**Next pair.** Otherwise the rest of A or R is erased. `A = 0` and `R = 1` are written right of
M, and the marker goes on M's third cell from the right. Then:

* if `m ≥ 2`, the separator between K and M moves one cell right: `(k + 1, m − 1)`;
* if `m = 1`, the separator is filled, K grows by one cell on the left (the anchor moves with
  it), and a new separator is cut after K's fourth cell: `(2, k)`.

The marker's place, counted from M's right end, is the same in both cases. The seed writes
`K = 2` and `M = 1` (the end of the pair `(2, 1)`, not a solution) and enters this step, so the
search starts at `(2, 2)`.

State budget of the 117-state design: seed 10, powers 42, next base and adding R into A 16,
compare and clear 16, restoring A and R 15, next pair 18.
