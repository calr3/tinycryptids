# The proof, in plain words

This is a guided tour of the Lean proof that the 74-state design `oppermann.txt` and the
45-state machine `machines/oppermann_45.txt` halt if and only if Oppermann's conjecture is
false. The proof is in `../lean/TinyCryptids/Oppermann/`, on top of the shared machine model
and routines in `../lean/TinyCryptids/Core/`. It is `../legendre`'s proof with a new advance
of the Q hole, a new growth of Q and a new bookkeeping of the intervals; each step below names
the lemma that carries it.

## What is proved

```lean
theorem TM.Oppermann.halts_iff : Halts delta start ↔
    ∃ n, 2 ≤ n ∧ ((∀ p, n * n - n < p → p < n * n → ¬ Prime p) ∨
      (∀ p, n * n < p → p < n * n + n → ¬ Prime p))
```

and the same for the merged machine (`TM.Oppermann.M45.halts_iff`, `delta2`). `Prime p` is `2 ≤ p ∧ ∀ d, d < p → 2 ≤ d → p % d ≠ 0` (`../lean/TinyCryptids/Defs.lean`).
Both theorems depend only on `propext`, `Classical.choice` and `Quot.sound`
(`../lean/Check.lean`).

## The idea

With `q(j) = ⌊j²/4⌋`, the two intervals of `n` are `(q(2n − 1), q(2n))` and
`(q(2n), q(2n + 1))`, so the conjecture is about the consecutive intervals `j = 3, 4, 5, …`,
of `⌈j/2⌉` numbers each: `[2, 4)`, `[4, 6)`, `[6, 9)`, `[9, 12)`, … The machine tests
`m = 2, 3, 4, …` by trial division as `../legendre` does, with a flag "a prime was seen in this
interval". Interval `j` is held by a block Q with `j` inner cells whose hole moves **two**
cells per number, so it runs off Q after `⌈j/2⌉` numbers; Q then grows by one cell.

## Part 1: arithmetic (`Spec.lean`)

* `FA n`, `FB n`: no prime in `(n² − n, n²)`, in `(n², n² + n)`.
* `FA_iff` (`n ≥ 3`): `FA n` iff none of `n² − n + i`, `i < n`, is prime, since
  `n² − n = n(n − 1)` is not (`mul_not_prime`). `FB_iff` (`n ≥ 2`): `FB n` iff none of
  `n² + i`, `i < n`, is prime.
* `not_FA_two`: 3 lies in `(2, 4)`, so `n = 2` fails only through `FB 2`.
* `mod_succ`, `add_mod_self_left'`: the residue of the mod walk, as in `../legendre`.

## Part 2: the machine on the tape (`Round.lean`)

The tape is `[1 0] Q 00 D 00 R`: Q with `q + 2` cells and its hole at cell `k + 1`
(`QX q k f`, read leftwards from Q's right end, with the flag part `FL f`), the trial divisor D
and `R = m − d`. The mod walk, the shift, the prime path and the rebuild are `../legendre`'s,
unchanged (`mw_step`, `mw_last_nodiv`, `mw_last_div`, `shift`, `tail_more`, `tail_zero`,
`prime_path`, `rebuild`). New:

| position of the hole | what the machine does | lemma |
|---|---|---|
| `k + 2 < q` | the hole moves two cells right, then `D := 2`, `R := m − 1`: `SHT (QX q (k + 2) f) 2 (d + r − 1)` | `qadv_next` |
| `k + 1 = q` or `k + 2 = q` | the hole runs off Q; the head runs left over Q: `IE q f d r` | `qadv_end` |
| `IE q false d r` | reads the unset flag: **halts** | `ie_halt` |
| `IE q true d r` | erases the flag, the 0 next to Q becomes Q's cell 0 and the old cell 0 the hole: `SHT (QX (q + 1) 0 false) 2 (d + r − 1)` | `ie_next` |

`seed_reach`: the fifteen seed states write `10111 00 1011 00 11` and reach `P6 (QX 3 0 false) 2`
(interval 3, `m = 2`, `r = 0`).

## Part 3: the main theorem for the design (`Main.lean`)

* `test`: `../legendre`'s trial division (by induction on `r`): from `SHT (QX q k f) d r` the
  machine reaches the Q hole with the flag set iff `d + r` is prime.
* `CS q i f m := SHT (QX q (2i) f) 2 (m − 2)`: before testing `m`, the `i`-th number of the
  interval held by `q` cells. `cand`: for an interval of `c` numbers with `q = 2c − 1` or
  `q = 2c`, `m` is tested and the machine goes to the next number (`i + 1 < c`), to the next
  interval `CS (q + 1) 0 false (m + 1)` (flag set), or halts (flag unset).
* `ival`, `ival0`: over `[b, b + c)` the machine halts iff none of the numbers is prime, else
  reaches `CS (q + 1) 0 false (b + c)`.
* `IB n := CS (2n) 0 false (n²)`. `interval`: from `IB n` the intervals `[n², n² + n)` and
  `[n² + n, (n + 1)²)` follow; if `FB n` or `FA (n + 1)` the machine halts, otherwise it
  strictly reaches `IB (n + 1)` (`IB_ne`, `reach1_of_ne`).
* `start_reach`: after the seed, 2 is prime (flag set), 3 is tested, and interval 4 starts:
  `IB 2`.
* (→) Without a counterexample every `IB n` strictly reaches `IB (n + 1)`, so the machine
  never halts (`not_halts_of_progress`). (←) `fails_shift` turns a counterexample `n` into
  `FB n`, or `FA n` with `n ≥ 3` (by `not_FA_two`), i.e. `FA ((n − 1) + 1)`; induction from
  `IB 2` reaches it (`haltAt_of`), in the explicit state `halt`.

## Part 4: the merged machine (`M45.lean`)

Generated by `gen_reduced_lean.py`: the merged table `delta2`, the state map `phi`, `compat`,
and `halts_iff` by `halts_iff_of_sim` with `haltAt_of`.

## What the proof does not cover

It says nothing about whether the conjecture is true, nor about running time (trial division
by every `d < m` in unary). That `M45.lean`, `machines/oppermann_45.txt`, the standard text in
`README.md` and the annotated listing are the same machine rests on the generator scripts.
