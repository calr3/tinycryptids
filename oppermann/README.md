# A Turing machine for Oppermann's conjecture

**Current best: `machines/oppermann_45.txt`, a 45-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff
Oppermann's conjecture is false**: iff for some `n ≥ 2` there is no prime in `(n² − n, n²)`
or none in `(n², n² + n)`. Lean proves this (`TM.Oppermann.M45.halts_iff`):

    Halts M45.delta2 M45.start2 ↔ ∃ n, 2 ≤ n ∧ ((∀ p, n * n - n < p → p < n * n → ¬ Prime p) ∨
      (∀ p, n * n < p → p < n * n + n → ¬ Prime p))

with `Prime` from `../lean/TinyCryptids/Defs.lean`. `RECORDS.md` lists the
machines, and `PROOF.md` walks through the proof in plain words.

The 45-state machine is obtained in two stages:

1. `oppermann.txt` is the readable **74-state design**, generated by `build.py`. The Lean proof
   is written for this machine (`TM.Oppermann.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition the
   run uses (an exact SAT search). `gen_reduced_lean.py` carries the theorem over, and
   `machines/oppermann_45_annotated.txt` is the same machine with each state named after its
   roles in the design.

## How it works

It is `../legendre`'s machine with other intervals. With the quarter-squares
`q(j) = ⌊j²/4⌋`, the two intervals of `n` are `(q(2n − 1), q(2n))` and `(q(2n), q(2n + 1))`,
so the conjecture is about the consecutive intervals `j = 3, 4, 5, …`: `[2, 4)`, `[4, 6)`,
`[6, 9)`, `[9, 12)`, `[12, 16)`, … Interval `j` holds `⌈j/2⌉` numbers, and its first number
`q(j)` is not prime for `j ≥ 4` (`n(n − 1)`, `n²`), so it has a prime iff the open interval
does. The machine tests `m = 2, 3, 4, …` in turn. Tape (blocks of 1s separated by `00`):

    [1 0] Q 00 D 00 R

* **Q** has `j + 2` cells; its hole (a single 0) at cell `2k + 1` marks `m = q(j) + k`. The
  hole moves **two** cells per number, so it runs off Q after `⌈j/2⌉` numbers.
* **The flag** (a prime was seen in this interval) is a 1 two cells left of Q.
* **D** (`d + 2` cells) is the trial divisor, **R** (`r + 2` cells) holds `r = m − d`.
* **Trial division** (`../legendre`'s mod walk): for `d = 2, …, m − 1`, `r` steps advance D's
  cyclic hole; `d ∣ m` iff it is back at cell 1. If no `d` divides `m`, `m` is prime: the
  flag is set.
* **Advance**: Q's hole moves two cells. If it runs off Q, interval `j` is over: the machine
  **halts** if the flag is not set; otherwise the flag is erased, the 0 between it and Q becomes
  Q's new cell 0 and the old cell 0 the hole: interval `j + 1`, one cell more.
* **Rebuild**: `D := 2`, `R := m − 1`, for `m + 1`.

The seed writes `10111 00 1011 00 11`: interval 3 at `m = 2`.

State budget of the 74-state design: seed 15, mod walk 23, shift 7, prime 8, advance Q and
the end of an interval 11, rebuild 10. Compared with `../legendre` (71), the two-cell advance
costs one state and the growth by one cell two.
