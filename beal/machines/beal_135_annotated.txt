; ============================================================================
; A 135-state, 2-symbol Turing machine that HALTS IFF BEAL'S CONJECTURE FAILS:
; iff a^x + b^y = c^z for some a, b, c >= 1, x, y, z >= 3 with gcd(a, b) = 1.
; Start on a blank tape in the first state. A transition to `halt` halts.
; Lean proof: lean/TinyCryptids/Beal/M135.lean, theorem TM.Beal.M135.halts_iff.
; ============================================================================
;
; HOW TO READ THIS FILE
;   The machine is the 225-state design of build.py / beal.txt with states
;   merged. States are merged only when their defined transitions agree, so
;   each state below plays one or more ROLES of the design (its name joins
;   them). Each transition line is tagged [role] with the role(s) that use it.
;   A '-' line is never used.
;
; TAPE:  x 00 y 00 z 00 a 00 b 00 c 00 M 00 A 00 R 00 Q
;   x, y, z: E + 1 cells, a cursor (hole) on cells 1 .. E; x keeps an anchor
;     hole on cell 1 between tuples.
;   a, b, c: beta + 3 cells, a cursor on cells 2 .. beta + 1.
;   M = 1 marker, A = a^x + b^y (2 + value cells), R the running power, Q scratch.
;
; SEARCH: NEXCOM order of the six block lengths minus 4 (every tuple).
; PER TUPLE:
;   walk    holes on a's and b's first cursor cells; each tick advances both
;           cyclically; when a's wraps, b's at its first cell -> coprime, at
;           its last -> not coprime (next tuple).
;   powers  R := 1; E rounds of R := R * beta (copy R beta - 1 times onto Q,
;           merge); for (x, a), (y, b), (z, c); the exponent cursor moves on
;           to the next block, the base cursor too; R is added into A.
;   compare zig-zag A against R: equal -> HALT; else clear, restore A, bring
;           the cursor left in a back to x as the anchor, next tuple.
; ============================================================================
