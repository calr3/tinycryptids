# The proof in plain words

Files: `../lean/TinyCryptids/SophieGermain/` — `Spec.lean` (arithmetic), `Walk.lean` (the mod
walk), `Round.lean` (the round end, the rebuild, the beep and the seed), `Main.lean` (the
candidates and the main theorems), `Machine.lean` and `M17.lean` (generated). Every routine is
proved for `deltaNB`, the design without its beep transition: a run of `deltaNB` is a run of
`delta` that never beeps (`deltaNB_sub`). Only the beep step itself uses `delta`.

1. **Arithmetic** (`Spec.sg_iff`). For odd `n ≥ 5`, `n` is a Sophie Germain prime iff every
   odd `e` with `3 ≤ e ≤ n − 2` is `Good n e` (divides neither `n` nor `2n + 1`). An even
   divisor of `n` or of `2n + 1` would make it even. An odd divisor `d < 2n + 1` of `2n + 1`
   has an odd cofactor `k ≥ 3`, so `3d ≤ 2n + 1` and `d ≤ n − 2`.
2. **The walk** (`Walk.walk_step`, `walk_all`). `W d r c k` is the walk with `k` of `r` steps
   done and D's hole on cell `c`. One step takes the hole to `(c + 2) % d`: no wrap, the wrap
   from `d − 2` to 0 (`W1`), or the wrap from `d − 1` to 1 (`W3`). By induction the hole ends
   on `2r % d`.
3. **The check** (`Round.walk_end`, `check_ok1`, `check_ok`, `check_fail`). After the walk,
   `E` erases R's last cell, `V` and `X` scan back to the hole and fill it: `KC d c j`, with
   `K1` on cell `c + 1`. If `c = d − 1` or `c ≤ d − 4`, `G0` ends on R's cell 0 after a block
   of `d + 1` ones (OK). If `c = d − 2` (with R not empty) or `c = d − 3`, the separator is
   filled and the rebuild starts for `n + 2` (FAIL). `Main.fail_iff`: with `n = d + r + 1` and
   `d` odd, `d` fails iff `2r % d` is `d − 2` or `d − 3` (`2n ≡ 2r % d + 2` mod `d`, and for odd
   `d`, `d ∣ n` iff `d ∣ 2n`: `mod_two_mul`). For `c = d − 2` R is never empty: that would mean
   `d ∣ d + 2`.
4. **Shift and beep** (`shift`, `beep_step`). If R has cells left, `G0` writes the new
   separator and the walk for `d + 2` starts (`WS (d + 2) (r − 2)`). If R is empty, `G0`
   reads 0 in `BeepCfg (n − 1)`: one block of `n − 1` ones. The beep moves left into `V`.
5. **Rebuild and seed** (`rebuild`, `seed`). `V` in a block of `a + b` ones runs to its left
   end, `X` and `K1` write `1 1`, and `G0` the separator: `CS (a + b + 3)`, the start of the
   next candidate. On a blank tape, `B2` reaches `BeepCfg 2`, the beep for `n = 3`.
6. **One candidate** (`Main.test`, by induction on `t` with `r = 2t + 1`, then `cand_sg`,
   `cand_not`). From `CS n`, the run reaches `BeepCfg (n − 1)` if `n` is a Sophie Germain
   prime and `CS (n + 2)` (without beeping) otherwise. `after_beep` continues from the beep
   to `CS (n + 2)`.
7. **Main theorems.** `reach_cs`: the run from the start reaches every `CS (2k + 5)`.
   `never_halts`: every candidate leads to the next one in at least one step
   (`not_halts_of_progress`). `quasihalts_iff`: if there are infinitely many Sophie Germain
   primes, each one above `2N + 5` gives a beep after step `N`; if they all lie below `N`,
   then from `CS (2N + 5)` on `deltaNB` never halts, so `delta` never beeps again
   (`quasihalts_of_sub`). `beeps_forever_iff` restates it.
8. **The standard machine** (`M17.lean`, generated by `gen_reduced_lean.py`): the same
   machine with its states renamed, transferred by `quasihalts_iff_of_sim` and
   `not_halts_of_sim`.
