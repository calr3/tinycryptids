# A Turing machine for long Barker sequences

**Current best: `machines/barker_84.txt`, an 84-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff a Barker
sequence of length greater than 13 exists**: a sequence of `±1`s whose every nontrivial aperiodic
autocorrelation `C_k = Σ_i a_i a_{i+k}` (`1 ≤ k < N`) has `|C_k| ≤ 1`. The longest known
Barker sequence has length 13, and it is conjectured that none is longer (odd lengths > 13 are
ruled out by Turyn and Storer; even ones would need length `4m²` and are excluded far beyond
`10^30`). Lean proves (`TM.Barker.M84.halts_iff`):

    Halts M84.delta2 M84.start2 ↔ ∃ a : List Int, 13 < a.length ∧ IsBarker a

with `autocorr` and `IsBarker` in `../lean/TinyCryptids/Defs.lean` (entries `±1`,
`(autocorr a k).natAbs ≤ 1` for `0 < k < a.length`). Nothing about Barker sequences is
assumed: the machine searches every candidate. The proof uses only `propext`,
`Classical.choice` and `Quot.sound`.

The 84-state machine is obtained in two stages: `barker.txt` (= `machines/barker_102.txt`) is
the readable **102-state design** generated by `build.py`, proved in Lean
(`TM.Barker.halts_iff`); `../tools/minimize_clique.py` merges it exactly (84 is optimal for
this design: 83 is unsatisfiable) and `gen_reduced_lean.py` carries the theorem over.

## The search

A candidate is a list of Booleans (`1` = +1) starting with `1` (a Barker sequence or its
negation starts with +1, and negation preserves every `C_k`). Candidates are enumerated as
binary numbers, last element least significant, from `1 0^13` (the smallest of length 14)
upwards; a carry out of the first element lengthens the candidate by one.

    for each candidate a (length N ≥ 14), in increasing order:
        for k = 1, 2, …, N − 1:
            S := Σ_{i < N−k} sgn(a_i, a_{i+k})      (+1 equal, −1 different)
            if |S| > 1: next candidate
        HALT                                         (a is a Barker sequence)

## The tape

Each element is a cell pair `[p][a]`: `a` the element, `p = 1` unmarked, `p = 0` marked.
A *dummy* position `[1 0]` precedes the candidate; left of it the tape is blank. Two markers,
`i` and `j = i + k`, point at the pair being compared. Right of the candidate: a gap `0 0`
and the signed counter `Z`: `1^(−S)` for `S ≤ 0`, `0 1^S` for `S > 0`.

* **Pass for shift k** (pairs from the right: `j` from `N − 1` down, `i = j − k`): move `i`
  one position left and read `a_i`; carry it right to `j`, compare with `a_j`, move `j`
  left; carry the result right to `Z` (`ZA` adds 1, `ZD` subtracts 1); back to `i`.
  When `i` reaches the dummy (the cell left of it is blank) the pass ends.
* **Rewind** (before the check): move `j` right, then `i` and `j` right together until `j` is
  the last position: the markers are now set for shift `k + 1`. If `j` is already last when
  the rewind starts, every shift has passed: **halt**.
* **Check**: `|S| ≤ 1` (Z is ``, `1` or `0 1`): erase `Z`, start the next pass.
  Otherwise erase `Z`, unmark `i`, add 1 to the candidate (the carry stops at the dummy at
  the latest, which then becomes the new first element and a new dummy is written), and set
  `i`, `j` on the last two positions (shift 1).
* **Seed**: a 4-bit counter left of the dummy (its top bit's marker cell is the sentinel)
  counts from 4 to 16; each count appends a `0` to the candidate `1 0`. At the overflow the
  candidate is `1 0^13` and its pass for shift 1 starts.

State budget of the 102-state design: seed 20, pair loop 40, end of pass and rewind 15,
check 6, next candidate 21.

## The proof (`../lean/TinyCryptids/Barker/`)

| File | Contents |
|------|----------|
| `Tape.lean` | Cell pairs (`U`, `UL`), the counter `Zs`, generic scanners over unmarked positions |
| `Z.lean` | The six counter updates (`zA`, `zD`) |
| `Pair.lean`, `Pass.lean` | One pair (`pair`), a whole pass: the counter ends at `psum a k` (`pass_n`) |
| `Rewind.lean`, `Check.lean` | End of a pass, the rewind (`rewind`), the halt (`rw_halt`), the check |

| `Round.lean` | A round: next shift, next candidate, or halt (`round`, `round_halt`) |
| `Seed.lean` | The counter seed reaches the first candidate's first pass (`seed`) |
| `Enum.lean` | `inc` from `1 0^13` reaches every candidate of length ≥ 14 (`cover`) |
| `Bar.lean` | `IsBarker` (on `List Int`) ⟺ `psum` on Booleans, with negation (`barker_iff`) |
| `Main.lean` | `halts_iff`: (←) the run reaches the Barker candidate and passes every shift; (→) otherwise the rounds make progress forever (`not_halts_of_progress`) |
