# The proof, in plain words

This is a guided tour of the Lean proof that the 106-state machine
`machines/feitthompson_106.txt` halts if and only if the Feit–Thompson conjecture is false. The
hand-written proof is about 1,850 lines in `../lean/TinyCryptids/FeitThompson/` (`Arith`,
`Blocks`, `Copy`, `Cyc`, `Horner`, `Trial`, `Pair`, `Main`, and the step tactics `Tac`); the
machine tables `Machine.lean` and `M106.lean` are generated. Each step below names the lemma
that carries it.

## What is proved

```lean
theorem TM.FeitThompson.halts_iff :
    Halts delta start ↔ ∃ p q, Prime p ∧ Prime q ∧ p ≠ q ∧ rep p q ∣ rep q p

theorem TM.FeitThompson.M106.halts_iff :
    Halts M106.delta2 M106.start2 ↔ ∃ p q, Prime p ∧ Prime q ∧ p ≠ q ∧ rep p q ∣ rep q p
```

* `rep b 0 = 0`, `rep b (n + 1) = rep b n + b^n`, so `rep b n = 1 + b + … + b^(n−1)`;
  `Prime p` is "`2 ≤ p` and no `d` with `2 ≤ d < p` divides `p`" (`TinyCryptids`,
  `../lean/TinyCryptids/Defs.lean`).
* `delta` is the 149-state design `feitthompson.txt` (generated by `build.py`, transcribed by
  `gen_lean.py` into `Machine.lean`), `start` its first state on a blank tape. `delta2` is the
  106-state machine (`M106.lean`), `start2` likewise.
* `Halts δ c`: started in `c`, the machine reaches a configuration with no transition
  (`../lean/TinyCryptids/Core/Basic.lean`, the model shared by every machine in the repository).

Both theorems depend only on `propext`, `Classical.choice` and `Quot.sound`
(`../lean/Check.lean` prints this).

## The idea

    for m = 3, 4, 5, …:
      if no prime p < m divides m:                (trial division by the list)
        for each prime p < m, largest first:
          if rep m p ∣ rep p m: HALT
        add m to the list

Everything is unary. A block holding `v` has `v + 2` cells, and a **cyclic hole** in cells
`1 … v` serves as a pointer. One routine, **CYC(counter, cycled)**, decides every
divisibility: the cycled hole goes round once, the counter hole advances before each of its
steps. Powers are never formed: `rep b e` is built by **Horner's rule** `R := b·R + 1`, with
the exponent hole counting rounds and the base hole counting copies of R.

## Part 1: arithmetic (`Arith.lean`)

**Lemma 1 (`rep_horner`, `rep_pos`).** `rep b (n + 1) = b · rep b n + 1`, and `rep b n ≥ 1`
for `n ≥ 1`.

**Lemma 2 (`rep_lt`).** For `1 ≤ p < q`: `rep q p < rep p q`. *Proof:* `rep_le`, by induction on `k = q − p`: with
`rep (q + 1) n ≤ p · rep q n` for `n ≤ p ≤ q` (`rep_succ_le`, from `(q + 1)^i ≤ p · q^i`,
`pow_le_mul`), `rep (q + 1) p ≤ p · rep q p ≤ p · rep p q < p · rep p q + 1 = rep p (q + 1)`.

**Lemma 3 (`ft_iff`).** The statement is equivalent to
`∃ p m, Prime p ∧ Prime m ∧ p < m ∧ rep m p ∣ rep p m`. *Proof:* a divisor of a positive number
is at most it, so by Lemma 2 in `rep p q ∣ rep q p` the larger prime is `p`; rename.

**Lemma 4 (`pl`, `mem_pl`, `prime_iff_pl`).** `pl m` is the increasing list of primes below
`m` (`pl_succ_prime`, `pl_succ_not`); for `m ≥ 2`, `m` is prime iff no element of `pl m`
divides it (`exists_prime_dvd`: a least divisor `≥ 2` is prime).

## Part 2: routines on the tape

**Blocks (`Blocks.lean`, `Copy.lean`).** `Blk`/`Gap` describe tapes made of blocks of 1s
separated by gaps that start and end with `00`; parsers ("scan to the next hole") cross them.
The copy loop is the one of `../fermat`: `copy_full` appends `r` cells to a block `Q` from
a block `R` of `r` cells, with a cursor hole walking R.

**CYC (`Cyc.lean`).** `nx c i` is the next position of a hole on `c` positions,
`nxs c i n` after `n` steps; `nxs_dvd`: `nxs c 1 v = 1 ↔ c ∣ v`. The cycle state `cyc2`
(the counter hole at `i`, the cycled hole at `j`) steps by `ctr_adv` (one counter advance,
wrapping or not) and `pc_part` (one cycled advance); `cyc_loop` runs it until the cycled hole
wraps, and `cyc_run`: started with both holes at cell 1, the machine reaches `kd3` if
`c ∣ v` and `kn3` otherwise, with the counter hole filled and the cycled hole back at 1.

**Horner (`Horner.lean`).** `eAtC` is the configuration at the exponent hole (position `ep`
of `e`), with base `β`, a skipped block `s` and `R = r` at the right end. `base_loop` /
`base_wrap`: the base hole goes round, appending `β − 1` copies of R, then the merge;
`exp_round`: one round, `r ↦ β·r + 1`; `exp_loop` and `hrn_rep` (`hrn β (rep β k) n =
rep β (k + n)`); `horner`: from `R = 1 = rep β 1`, the exponent hole runs to `e` and wraps,
the machine is at `hd1` with `R = rep β e`.

**Trial pass (`Trial.lean`).** The tape is `L 00 1 00 P1 … 00 M` with the list
`pre ++ p :: post` (its `seps`); `TC m pre p post` is the machine at P's cell 1 starting the
trial cycle. `trial_cyc` = CYC(P, L). Then `trial_div` (`p ∣ m`) runs to M, and `next_cand`
grows M and L and restarts at `TC (m + 1) [1] p1 rest`; `trial_next` marks the next block;
`trial_prime` (no next block: M) retreats to the last prime, `PC m pre p []`, the pair
checkpoint (`PC`: at `pw1`, the marker on `p`).

**Pair step (`Pair.lean`).** `pair_h1`: from `PC`, Horner with base `p`, exponent L writes
`A = rep p m`; `probe_*` reads the blocks after the exponent to see which run ended;
`pair_h2`: Horner with base M, exponent `p` writes `B = rep m p`; `test_run`: CYC(B, A).
`halt_kd3`: `kd3` with nothing right of B halts. Otherwise `cleanup` erases A and B and
`back` + `retreat` reach `PC m pre0 q (p :: post)`. Together: **`pair_step`** — if
`rep m p ∣ rep p m` the machine halts from `PC`, else it reaches the checkpoint of the
previous list entry. **`per_prime`**: from `PC m [] 1 (pl m)` (P0 marked), Horner with base 1
copies `m` (`rep_one`), the copy becomes M, and the machine reaches `TC (m + 1) [1] 2 …`.

## Part 3: the main theorem (`Main.lean`)

The checkpoints are `TC m pre p post` with `GT` (`3 ≤ m`, the list is `1 :: pl m`, the
entries before `p` do not divide `m`) and `PC m pre p post` with `GP` (`m` prime, the list is
`1 :: pl m`). `TS m = TC m [1] 2 (pl m).tail` is the start of a trial pass.

* `start_reach`: the seed reaches `TS 3`.
* `trial_step`: from a `GT` checkpoint the machine reaches (in at least one step) `TS (m + 1)`
  if `p ∣ m` (then `m` is composite), the next `GT` checkpoint, or, at the end of the list,
  the `GP` checkpoint of the largest prime (`m` is prime by `prime_iff_pl`).
* `pair_trans`: from a `GP` checkpoint with `p > 1` the machine halts if `rep m p ∣ rep p m`,
  else reaches the previous `GP` checkpoint; `pair_zero`: at `p = 1`, it reaches `TS (m + 1)`.
* **`not_halts`**: without a counterexample every `Good` configuration reaches another one
  (`progress`), so the run never halts.
* **`haltAt_of`**: with a counterexample `(p, m₀)`: `pass_pairs` and `pass_trial` show, by
  induction along the list, that every checkpoint of round `m` leads to a halt when `TS (m + 1)`
  does or when round `m` holds a counterexample. So `TS m₀` halts, and by induction on
  `m₀ − m` every `TS m` with `3 ≤ m ≤ m₀`, in particular `TS 3`, which the start reaches.
* `halts_iff` combines them with `ft_iff`.

## Part 4: the transfer (`M106.lean`)

`minimize.py` merges only states whose defined transitions agree, so the 106-state machine
follows the same run with renamed states. `gen_reduced_lean.py` writes the merged table, the
state map `phi`, and a `compat` check by `decide`; `halts_iff_of_sim` gives the theorem for
`delta2`.
