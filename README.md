# Small Turing machines for open problems, proven in Lean

Each folder holds Turing machines (2 symbols unless noted) that start on a blank tape and halt
iff a mathematical statement fails, with a Lean 4.15.0 proof (core library only, no Mathlib) of exactly that. Every theorem depends only
on `propext`, `Classical.choice` and `Quot.sound`; run
`cd lean && lake build && lake env lean Check.lean` to check them all.

## Machines

| Folder | Conjecture | [Class](https://en.wikipedia.org/wiki/Arithmetical_hierarchy) | Halts iff | Best | Design |  Theorem |
|--------|------------|:-----:|-----------|-----:|-------:|----------|
| [`weakcollatz/`](https://github.com/calr3/tinycryptids/tree/main/weakcollatz) | [Collatz conjecture (cycles)](https://en.wikipedia.org/wiki/Collatz_conjecture) | Π₁ | the Collatz sequence has a cycle other than 1 → 4 → 2 → 1 | 14 | 14 | `TM.WeakCollatz.halts_iff` |
| [`weakcollatz/sym3/`](https://github.com/calr3/tinycryptids/tree/main/weakcollatz/sym3) | [Collatz conjecture (cycles)](https://en.wikipedia.org/wiki/Collatz_conjecture) (3-symbol version) | Π₁ | the Collatz sequence has a cycle other than 1 → 4 → 2 → 1 | 10 | 10 | `TM3.WeakCollatz.halts_iff` |
| [`oddperfect/`](https://github.com/calr3/tinycryptids/tree/main/oddperfect) | [Odd perfect numbers](https://en.wikipedia.org/wiki/Perfect_number#Odd_perfect_numbers) | Π₁ | an odd perfect number exists (`n` odd with `n` = the sum of its proper divisors) | 37 | 50 | `TM.OddPerfect.M37.halts_iff` |
| [`sierpinski/`](https://github.com/calr3/tinycryptids/tree/main/sierpinski) | [Sierpiński problem](https://en.wikipedia.org/wiki/Sierpiński_number#Smallest_Sierpiński_number) | Σ₁ | every odd `k < 78557` has a prime `k·2^n + 1` | 60 | 83 | `TM.Sierpinski.M60.halts_iff` |
| [`fermat/`](https://github.com/calr3/tinycryptids/tree/main/fermat) | [Fermat's Last Theorem](https://en.wikipedia.org/wiki/Fermat's_Last_Theorem) † | Π₁ | `x^E + y^E = z^E` for some `E ≥ 3` and `x, y, z ≥ 1` | 90 | 127 | `TM.Fermat.M90.halts_iff` |

"Design" is the readable machine generated by the folder's `build.py`; "Best" is
it with compatible states merged by an exact SAT search (`minimize.py` or `minimize_clique.py`), when that
helps (the 14-state weak Collatz machine has no states to merge, so both are the same).
Both are proven; a merged machine's theorem is transferred from the design's. 
Earlier machines for the same conjecture stay in subfolders with their own proofs
(`weakcollatz/m16/`, `weakcollatz/v1/`). The 3-symbol machine (`weakcollatz/sym3/`, BB(10, 3))
is proven on a 3-symbol copy of the machine model (`Core/Basic3.lean`, namespace `TM3`) and
shares the arithmetic (`WeakCollatz/Spec.lean`, `Cycle.lean`) with the 2-symbol proof.
Each folder's `RECORDS.md` lists every machine, `README.md` explains the algorithm and
gives the machine in bbchallenge standard text, `PROOF.md` walks through the proof in
plain words, and `machines/*_annotated.txt` describes every state.

† Fermat's Last Theorem is of course a theorem since Wiles, so a machine that never halts
would be correct too, but proving that would need Wiles' proof. This machine is included as
a historical curiosity: James Randels' dissertation *Studies in Turing Machines* (1965) estimated
that fewer than 400 states would suffice for a Fermat counterexample searcher, without
building one. The proof here does not use Wiles: it shows only that the machine halts iff
a counterexample exists.

The shared Lean code is the machine model (`Core/`), generic routines (`Core/Routines.lean`) and the statement definitions (`Defs.lean`).

## Layout

| Path | Contents |
|------|----------|
| `<conjecture>/` | One hand-designed machine: `build.py`, tests, `machines/`, `README.md`, `RECORDS.md`, and `gen_lean.py`/`gen_reduced_lean.py`/`annotate.py` |
| `lean/` | **All proofs**, one Lake project: `TinyCryptids/Core/` (the shared machine model), `TinyCryptids/Defs.lean` (every definition used in a statement), `TinyCryptids/<Machine>/` (namespace `TM.<Machine>`), `Check.lean`. See `lean/README.md` |
| `tools/` | Shared Python tools: `tm.py` (format, standard text), `sim.c` (`gcc -O2 -o tools/sim tools/sim.c`), `same_run.py`, `minimize.py`, `minimize_clique.py`, `minimize_dimacs.py`, `greedy_merge.py`, `leangen.py` |
