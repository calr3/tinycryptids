# Small Turing machines for open problems, proven in Lean

Each folder holds Turing machines (2 symbols unless noted) that start on a blank tape and halt
iff a mathematical statement fails, with a Lean 4.15.0 proof (core library only,
no Mathlib) of exactly that. Every theorem depends only on `propext`,
`Classical.choice` and `Quot.sound`; run
`cd lean && lake build && lake env lean Check.lean` to check them all.

## Machines

| Folder | Conjecture | Halts iff | Best | Design | Lean lines (proof + generated) | Theorem |
|--------|------------|-----------|-----:|-------:|------:|---------|
| `weakcollatz/` | [Collatz conjecture (cycles)](https://en.wikipedia.org/wiki/Collatz_conjecture) | the Collatz map has a cycle other than 1 → 4 → 2 → 1 | 14 | 14 | 798 + 59 | `TM.WeakCollatz.halts_iff` |
| `weakcollatz/sym3/` | the same, **3 symbols** | the same | 10 | 10 | 491 + 57 | `TM3.WeakCollatz.halts_iff` |

"Design" is the readable machine generated by the folder's `build.py`; "Best" is
it with compatible states merged by an exact SAT search (`minimize.py`), when that
helps (the 14-state weak Collatz machine has no states to merge, so both are the same).
Both are proven; a merged machine's theorem is transferred from the design's. The Lean
line counts (`wc -l`, comments included) give the hand-written proof of the design and
the generated files for the design and the best machine (`Machine.lean`, `M<k>.lean`).
Earlier machines for the same conjecture stay in subfolders with their own proofs
(`weakcollatz/m16/`, `weakcollatz/v1/`). The 3-symbol machine (`weakcollatz/sym3/`, BB(10, 3))
is proven on a 3-symbol copy of the machine model (`Core/Basic3.lean`, namespace `TM3`) and
shares the arithmetic (`WeakCollatz/Spec.lean`, `Cycle.lean`) with the 2-symbol proof.
Each folder's `RECORDS.md` lists every machine, `README.md` explains the algorithm and
gives the machine in bbchallenge standard text, `PROOF.md` walks through the proof in
plain words, and `machines/*_annotated.txt` describes every state.

The shared Lean code is the machine model (`Core/`, 612 lines, and 137 more for the 3-symbol
model `Basic3.lean`) and the statement definitions (`Defs.lean`, 22).

## Layout

| Path | Contents |
|------|----------|
| `<conjecture>/` | One hand-designed machine: `build.py`, tests, `machines/`, `README.md`, `RECORDS.md`, and `gen_lean.py`/`gen_reduced_lean.py`/`annotate.py` |
| `lean/` | **All proofs**, one Lake project: `TinyCryptids/Core/` (the shared machine model), `TinyCryptids/Defs.lean` (every definition used in a statement), `TinyCryptids/<Machine>/` (namespace `TM.<Machine>`), `Check.lean`. See `lean/README.md` |
| `tools/` | Shared Python tools: `tm.py` (format, standard text), `sim.c` (`gcc -O2 -o tools/sim tools/sim.c`), `same_run.py`, `minimize.py`, `minimize_dimacs.py`, `greedy_merge.py`, `leangen.py` |
