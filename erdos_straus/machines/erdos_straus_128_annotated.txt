; ============================================================================
; A 128-state, 2-symbol Turing machine that HALTS IFF THE ERDOS-STRAUS
; CONJECTURE IS FALSE, i.e. iff some n >= 2 has no solution of
; 4/n = 1/x + 1/y + 1/z in positive integers.
; Start on a blank tape in the first state. A transition to `halt` halts.
; Lean proof: lean/TinyCryptids/ErdosStraus/M128.lean, theorem TM.ErdosStraus.M128.halts_iff.
; ============================================================================
;
; HOW TO READ THIS FILE
;   The machine is the 187-state design of build.py / erdos_straus.txt with
;   states merged. States are merged only when their defined transitions
;   agree, so each state below plays one or more ROLES of the design (its name
;   joins them). Each transition line is tagged [role] with the role(s) that
;   use it. A '-' line is never used. The seed roles run once at the start and
;   only ever read 0, so each of them doubles as a step of some other routine.
;
; THE SEARCH: a solution sorted x <= y <= z has n < 4x <= 3n; with a = 4x - n,
;   m = nx and D = ay - m = 4xy - n(x+y): D >= 1, D | my (z = my/D) and
;   D <= m (z >= y). Any D >= 1 with D | my is a solution. So for each n the
;   machine tries x = 1, 2, ... (U = 4x), skips x while U <= n, halts when
;   U > 3n, and tries y = 1, 2, ... while W = ay <= 2m + 2, testing D = W - m
;   when W > m. A hit moves on to n + 1.
;
; TAPE LAYOUT (blocks of 1s separated by 00, a hole is a single 0):
;
;      A 00 R 00 N 00 M 00 K [00 D 00 P]
;
;   A  a+1 cells (a = 0 in the debt phase U <= n); the consume cursor
;   R  2n+3-a cells. Debt phase: its hole on cell 2n+1-2U, two cells per unit
;      of U. Afterwards every unit of U moves the separator A|R right: A grows,
;      R shrinks; HALT when R would keep fewer than 3 cells (a > 2n)
;   N  n+1 cells (its cursor copies n onto M and K)
;   M  m+1 cells (its cursor copies m onto P)
;   K  the y counter: m+4 cells, hole moving left from cell m+2 (W = 0) to
;      cell 1 (W = m+1); then the hole stays and each unit moves the separator
;      K|D left (D grows) until K = 1 0 1
;   D  d+1 cells, d = max(1, W - m);  P  p+1 cells, p = m y
;
; ALGORITHM
;   x step   M += n and K += n (N loop); the 4 units of U: the debt hole walks
;            8 cells left, or (crossing / after it) separator moves A|R; the
;            check of R; set up K's hole, D = 11, P = 1
;   y step   P += M; W += a (one unit of K per cell of A); in the second lap
;            the mod walk on D 00 P (../oddperfect): d | p is a hit (n step),
;            otherwise D's hole is filled; K = 1 0 1 ends the y loop (x step)
;   n step   erase M, K, D, P; N += 1; R absorbs A (R += a + 2), A := 1 two
;            cells further left; R's hole; M = 1, K = 1111
;   seed     write 11 00 1111 00 11, the end of a solved n = 1
; ============================================================================
