# A Turing machine for the Erdős–Straus conjecture

**Current best: `machines/erdos_straus_128.txt`, a 128-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff the
Erdős–Straus conjecture is false**: iff some `n ≥ 2` has no solution of
`4/n = 1/x + 1/y + 1/z` in positive integers. Lean proves this
(`TM.ErdosStraus.M128.halts_iff`):

    Halts M128.delta2 M128.start2 ↔
      ∃ n, 2 ≤ n ∧ ∀ x y z, 1 ≤ x → 1 ≤ y → 1 ≤ z → 4 * x * y * z ≠ n * (x * y + y * z + z * x)

`RECORDS.md` lists the machines, and `PROOF.md` walks through the
proof in plain words.

The 128-state machine is obtained in two stages:

1. `erdos_straus.txt` is the readable **187-state design**, generated by `build.py`. The Lean
   proof is written for this machine (`TM.ErdosStraus.halts_iff`).
2. `../tools/minimize_clique.py` merges states of the design that never disagree on a
   transition the run uses (an exact SAT search: 127 is unsatisfiable, so 128 is optimal for
   this design). `gen_reduced_lean.py` carries the theorem over, and
   `machines/erdos_straus_128_annotated.txt` is the same machine with each state named after
   its roles in the design.

## The search

A solution sorted `x ≤ y ≤ z` has `4/n ≤ 3/x` and `1/x < 4/n`, so `n < 4x ≤ 3n`. With
`a = 4x − n`, `m = nx` and

    D = ay − m = 4xy − n(x + y)

the equation reads `zD = my`: so `D ≥ 1`, `D ∣ my`, and `z ≥ y` gives `D ≤ m`. Conversely any
`x, y` with `D ≥ 1` and `D ∣ my` give the solution `z = my / D`. So:

    for n = 2, 3, …:
      for x = 1, 2, …:                  U = 4x
        if U ≤ n: next x                (a ≤ 0)
        if U > 3n: HALT                 (no solution for n)
        for y = 1, 2, … while ay ≤ 2m + 2:
          if m < ay and (ay − m) ∣ my: next n

(`ay ≤ 2m + 2` instead of `2m`: the last two tests are spare, and cheaper than an exact
bound.) Everything is done by additions: `a` and `m` grow by 4 and `n` per x, `W = ay` and
`p = my` by `a` and `m` per y.

## How it works

The tape, left to right (blocks of 1s, separators `0 0`, a hole is a single 0):

    A 00 R 00 N 00 M 00 K [00 D 00 P]

* **A** (`a + 1` cells) and **R** (`2n + 3 − a` cells) hold `U`. While `U ≤ n` (the *debt*,
  `a = 0`), R has a hole on cell `2n + 1 − 2U`: it walks two cells left per unit of `U`, so
  it falls off R exactly when `U` passes `n`. From then on each unit moves the separator
  `A | R` one cell right (`a += 1`): A is `a` itself, and R counts down to the bound; the
  machine **halts** when R would keep fewer than 3 cells, i.e. `a > 2n` (`4x > 3n`).
* **N** (`n + 1` cells): its cursor adds `n` to M and K once per x.
* **M** (`m + 1` cells): its cursor adds `m` to P once per y.
* **K** (`m + 4` cells at the start of a y loop) is the y counter for `W = ay`: one *unit*
  per cell of A. First lap: K's hole moves left from cell `m + 2` to cell 1 (`W = m + 1`).
  Second lap: the hole stays on cell 1 and each unit moves the separator `K | D` one cell
  left, so **D** (`d + 1` cells) grows: `d = W − m`. When K is `1 0 1` (`W = 2m + 2`) the
  y loop is over.
* **P** (`p + 1` cells), `p = my`.

**The x step**: the N loop (`M += n`, `K += n`: M's separator moves one cell right and K gets
two cells at its end, per cell of N), then the four units of `U` (in the debt the hole walks
8 cells; when it falls off, the remaining units are separator moves), the check of R, and the
setup of the y loop: K's hole on its last-but-one cell, `D = 11`, `P = 1`.

**The y step**: `P += M`; `a` units of the y counter; in the second lap the test
`d ∣ p`, `../oddperfect`'s mod walk on `D 00 P` (D's hole cyclic, home on D's last cell;
P's hole counts `p` steps). The setup does the walk's first step by hand. A divisor is a hit:
the **n step**. Otherwise D's hole is filled and the next y step starts. If the y counter
stops (`K = 1 0 1`), K and D are merged back into K (`m + 4` cells), P is erased, the A cursor
that the stop left behind is filled, and the next x step starts.

**The n step**: erase M, K, D, P; `N += 1`; R absorbs A and its separator (`R += a + 2`,
`2n + 5` cells) and `A := 1` is written two cells further left; R's hole on its last-but-one
cell (`U = 0`); `M = 1`, `K = 1111`; on to the x step for `x = 1`.

The seed writes `11 00 1111 00 11`, the end of a solved `n = 1`, and enters the n step,
so the search starts at `n = 2`.

State budget of the 187-state design: x step 57 (N loop 20, units of `U` and the check 22,
setup 15), y step 72 (`P += M` 18, the y counter 30, the test 24), end of the y loop 15,
n step 31, seed 12.
