# A Turing machine for the Agoh–Giuga conjecture

**Current best: `machines/agoh_giuga_100.txt`, a 100-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff the
Agoh–Giuga conjecture is false**, i.e. iff some composite `n` satisfies Giuga's congruence
`1^(n−1) + 2^(n−1) + … + (n−1)^(n−1) ≡ −1 (mod n)`. Lean proves this
(`TM.AgohGiuga.M100.halts_iff`):

    Halts M100.delta2 M100.start2 ↔ ∃ n, 2 ≤ n ∧ ¬ Prime n ∧ n ∣ powSum n (n - 1) + 1

with `Prime` and `powSum m k = 0^k + 1^k + … + (m−1)^k` from `../lean/TinyCryptids/Defs.lean`. Every prime satisfies the congruence (Fermat's little theorem), so the open half of the
conjecture is that no composite does. `RECORDS.md` lists the machines, and `PROOF.md` walks
through the proof in plain words.

The 100-state machine is obtained in two stages:

1. `agoh_giuga.txt` is the readable **167-state design**, generated by `build.py`. The Lean proof
   is written for this machine (`TM.AgohGiuga.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition the
   run uses (an exact SAT search; `kissat404` and `cadical195` both reach 100).
   `gen_reduced_lean.py` carries the theorem over, and `machines/agoh_giuga_100_annotated.txt`
   is the same machine with each state named after its roles in the design.

## The search

For `n = 4, 5, 6, …` (2 and 3 are prime) and the bases `i = n − 1, n − 2, …, 2`, the machine
computes `i^(n−1)` in unary and adds `i^(n−1) − 1` to a counter `B` mod `n`. After each base it
checks `B`; the first time `B ≠ 0` it sets a flag. At the end of the round

    B = Σ_{i=2}^{n−1} (i^(n−1) − 1) ≡ 1^(n−1) + … + (n−1)^(n−1) + 1   (mod n)

and the machine **halts iff the flag is set and `B = 0`**:

* if `n` is prime, every `i^(n−1) ≡ 1` (Fermat), so `B` stays 0 and the flag is never set;
* if `n` is composite, a divisor `d` of `n` (`2 ≤ d < n`) has `d^(n−1) ≢ 1 (mod n)` (`d` would
  divide 1), so the step at `d` changes `B` and some check sees `B ≠ 0`.

So the flag says "composite" without a primality test, and the last `B` is Giuga's sum.

## How it works

A number `v` is a block of `v + 2` ones; its cells `1 … v` are the positions of a **cyclic hole**
(a single 0) that advances one cell right and wraps from cell `v` to cell 1. The tape:

    N 00 I 00 J 00 K 00 S 00 R [00 Q]

* **N** holds `n`. Its hole (at cell 1 at rest) is the exponent of the Horner run.
* **I** holds the base `i`, its hole at cell 1. **J** has no hole and `n − i + flag` cells:
  `|I| + |J|` is fixed during a round, and `i − 1` moves the I/J separator one cell left.
* **K** has no hole: 2 cells, or 1 once the flag is set (the J/K separator one cell right).
* **S** holds `n`; its hole is at cell `B + 1`.
* **R** = `101` (it holds 1) between bases.

One base:

* **Horner run** (`../firoozbakht`'s): `n − 1` rounds `R := i · R`, one per advance of N's hole
  (the base hole goes round, `i − 1` copies of R are appended after a `00`, the separator is
  filled and two cells erased). S's hole is skipped by the parsers. Now `R = i^(n−1)`.
* **consume**: R's last cell is erased and S's hole advances, until `R = 101` again:
  `B += R − 1`.
* **check**: a parser finds S's hole. Not at cell 1: the flag is set (two cells left of S
  rewritten: `.. 1 00 11` → `.. 11 00 1`, idempotent).
* **shift**: two scans find I's end. If `i > 2`, I's last cell joins the I/J separator, whose
  last cell becomes J's new cell 0 (`i − 1`), and the next Horner run starts.
* **round end** (`i = 2`): I's hole and the I/J separator are filled, a parser finds S's hole:
  at cell 1 with `K = 1` the machine **halts**. Otherwise the **reset** for `n + 1`, right to left
  from S: S's hole is filled, S grows by a cell on its left with its hole at the new cell 1,
  `K := 11`, `J := 1`, the I/J region takes the last two cells of N and I gets the rest (`n`),
  N grows by three cells on its left with its hole at the new cell 1; then the Horner run.

The seed writes the end of round 3 (`N = 3`, the region filled, `K = 11`, S without a hole,
`R = 101`) and runs into the reset: round 4 starts.

State budget of the 167-state design: seed 34, Horner run 53, consume 21, check and shift 20,
round end and reset 39. After merging every seed state is also a step of another routine; most
of the states that stay alone are the 20 parsers.

Shared tools in `../tools/`: `tm.py`, `sim.c` (`gcc -O2 -o ../tools/sim ../tools/sim.c`),

`../lean/TinyCryptids/AgohGiuga/` (see `../lean/README.md`).

The machine computes the powers in unary, so it is slow: the checks of rounds 4–6 are done after
2·10⁷ steps, but the first base of round 7 (`6^6 = 46,656`) is not done after 3·10⁹.
