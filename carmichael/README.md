# A Turing machine for Carmichael's totient conjecture

**Current best: `machines/carmichael_80.txt`, an 80-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff
Carmichael's totient conjecture fails**: iff some `m ≥ 1` has `φ(n) ≠ φ(m)` for every
`n ≠ m`. Lean proves this (`TM.Carmichael.M80.halts_iff`):

    Halts M80.delta2 M80.start2 ↔ ∃ m, 1 ≤ m ∧ ∀ n, n ≠ m → totient n ≠ totient m

`RECORDS.md` lists the machines, and `PROOF.md` walks through the proof in plain words.

The 80-state machine is obtained in two stages:

1. `carmichael.txt` is the readable **117-state design**, generated by `build.py`. The Lean
   proof is written for this machine (`TM.Carmichael.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition
   the run uses (an exact SAT search). `gen_reduced_lean.py` carries the theorem over, and
   `machines/carmichael_80_annotated.txt` is the same machine with each state named after its
   roles in the design.

## The search

    for v = 2, 3, ...:
        count the M in [2, s + 1] with φ(M) = v      (s + 1 ≥ 2 v², s grows with v)
        if exactly one: HALT

Every `n` with `φ(n) = v` satisfies `n ≤ 2 v²` (`n ≤ 2 φ(n)²`, `totient_bound` in
`../lean/TinyCryptids/Carmichael/Totient.lean`). So a window with exactly one match is a
counterexample, and a counterexample `m` makes the window of `v = φ(m)` hold exactly one match
(`v ≥ 2`, since `φ(1) = φ(2) = 1`). A window stops at its second match.

**φ without division.** For `M ≥ 2`, `φ(M)` is the number of `k` in `[1, M − 1]` with
`gcd(k, M − k) = 1`. The machine tests the pair `(k, r) = (k, M − k)` by a walk: `0, k, 2k, …`
modulo `r` reaches `1` before it returns to `0` iff `gcd(k, r) = 1` (a common divisor
`g > 1` keeps the walk on multiples of `g`; with `gcd = 1`, `k` has an inverse modulo `r`).

## How it works

The tape, left to right (blocks of slots, separators `0 0`, a hole is a single `0`):

    1 K 00 1 R 00 V 1 00 f 0 B 1

* **K, R** (`k` and `r` slots, `k + r = M`). Each has one hole. A *tick* moves both holes one
  slot right, cyclically. When K's hole wraps (every `k` ticks), R's hole has just walked `k`
  more slots: if it was on R's first slot (walk position 1 after the tick) the pair is
  coprime, if on its last (position 0) it is not. Both holes end on their first slots.
* **V** (`v + 1` slots). Each coprime pair moves V's hole one slot left, from slot `v + 1`;
  after more than `v` pairs there is no hole. At the round end V's hole is on slot 1 iff
  `φ(M) = v`.
* **Sweep.** After each test the separator moves one cell right, `(k, r) → (k + 1, r − 1)`,
  until `r = 1`. The round end then turns `(M − 1, 1)` into `(1, M)` (the next round).
* **f** is set at the first match. A second match ends the window early.
* **B** (`s` slots) has a hole that moves one slot left per round; when it runs off B, the
  window is over, and the machine halts iff `f = 1`.
* **Next v.** V gains a slot, whose hole is a cursor: each step appends four slots to B and
  moves the cursor one slot left, so `s` grows by `4v + 7` (from `s = 11` at `v = 2`), which
  keeps `s + 1 ≥ 2 v²`. K/R is erased back to `(1, 1)`.

The seed writes V with two slots and runs the next-v routine, which gives `v = 2`, `s = 11`.
