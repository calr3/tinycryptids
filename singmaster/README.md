# A Turing machine for Singmaster's bound 8

**Current best: `machines/singmaster_77.txt`, a 77-state, 2-symbol Turing machine** (named-state
format, see `../tools/tm.py`). Started on a blank tape, it **halts iff some
`N ≥ 2` occurs at least 9 times in Pascal's triangle**, i.e. iff "no number above 1 occurs more
than 8 times" (the concrete form of Singmaster's conjecture; 3003 occurs 8 times) is false.

Lean proves this (`TM.Singmaster.M77.halts_iff`):

    Halts M77.delta2 M77.start2 ↔
      ∃ N, 2 ≤ N ∧ ∃ l : List (Nat × Nat), l.Nodup ∧ 9 ≤ l.length ∧ ∀ x ∈ l, choose x.1 x.2 = N

`choose` is in `../lean/TinyCryptids/Defs.lean`. `PROOF.md` walks through the proof in plain words, and
`RECORDS.md` lists the machines.

The 77-state machine is obtained in two stages:

1. `singmaster.txt` is the readable **105-state design**, generated by `build.py`. The Lean proof
   is written for this machine (`TM.Singmaster.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition the
   run uses (an exact SAT search, kissat404). `gen_reduced_lean.py` carries the theorem over, and
   `machines/singmaster_77_annotated.txt` is the same machine with each state named after its roles.

## The search

Every occurrence of `N ≥ 2` lies in a row `n ≤ N` (`choose_range`), and row `N` holds `N`
exactly twice (`k = 1` and `k = N − 1`, for `N ≥ 3`). So it suffices to count the entries equal to
`N` in rows `0 … N − 1` and halt when the count reaches **7** (`occ_iff` in `Spec.lean`:
`(∃ l, l.Nodup ∧ T + 2 ≤ l.length ∧ ∀ x ∈ l, choose x.1 x.2 = N) ↔ T ≤ tcnt N N`).

The triangle is kept on the tape and grows by one row per `N`:

    for N = 2, 3, …:   (rows 0 … N − 1 are on the tape)
        count := number of entries equal to N;  HALT when it reaches 7
        append row N, computed from row N − 1;  N := N + 1

## Tape

All numbers in unary; a block of `v + 2` cells holds `v`; a hole is a single 0 inside a block.

    C 0 N 000 row0 000 row1 000 … 000 row(N−1)

* **C**: 9 cells, a hole at cell `1 + (matches so far)`. A match moves the hole one cell right; when
  the cell two to its right is the separator (7th match) the machine halts.
* **N**: `N + 2` cells with a cursor hole, at cell `N` between comparisons.
* **rows**: entries `C(n, 0) … C(n, n)` as blocks separated by `00`; rows separated by `000`.

**Compare** (each entry E in tape order): E's cursor starts at cell 1 and moves right, N's cursor
moves left from cell N, in lockstep. `E = N` iff E's cursor is exhausted in the round where N's
cursor is at cell 1 (then C += 1). N's cursor then returns to cell N and the next entry gets a hole.

**Next row** (after four 0s, the end of the triangle): built at the end from the last row, read
right to left (rows are palindromes, `prow_reverse`). For each cell of a source block the last two
blocks of the new row grow by one (append two cells, move the separator one cell right); a new
source block starts a new block (`1 00 111`). This is `pascal` on the reversed row
(`pascal_prow`). Then N grows by a cell on its left (C moves one cell left) and C's hole returns
to cell 1.

**Seed**: C, `N = 1` and row 0, entering at the end of the triangle (so row 1 is built next).
