# The proof, in plain words

The Lean files are in `../lean/TinyCryptids/PA/` (namespace `TM.PA`). The main theorem is

```
TM.PA.M309.halts_iff : Halts delta2 start2 ↔ TinyCryptids.Wff.Provable (TinyCryptids.Wff.el 0 0)
```

for the 309-state machine `machines/pa_309.txt`, where `Wff.Provable` is provability in the theory
T of `README.md` (defined in `../lean/TinyCryptids/Defs.lean`: formulas with `=` and `∈`, Tarski's
S2 axioms B1–B8, Friedman's scheme E, modus ponens and generalisation). Axioms: `propext`,
`Classical.choice`, `Quot.sound`.

The proof has five layers. They meet at `Run.lean` (`from_main`) and `Main.lean` (`halts_iff`).

## 1. The compiled machine (`Machine.lean`, `Dag.lean`, `M309.lean`)

* `Machine.lean` defines, for any decision DAG `dag`, the machine TMBuilder compiles from it:
  `St` has the framework states (boot, `1b.reg.*`, the register chains `chI k`/`chD k`, the
  shifts, the returns, cleanup, the leaves `incL r`/`decL r`, dispatch, root, `6.break.0/1`,
  `6.continue.0/1`) and one state `node i` per DAG node. `delta dag main` is TMBuilder's
  transition table: a node reading `0` goes to its car, reading `1` to its cdr, with the
  special transitions for `_break.k`, `_continue.k` and `halt` (`carTr`, `cdrTr`).
* `Dag.lean` (generated by `gen_lean.py`) is the program's DAG, 229 nodes, with two
  certificate tables: `zrT` (most trailing zeros of a program counter reaching a node) and `depT`
  (the cell of its bit).
* `M309.lean` (generated): the 309-state table `delta2`, the state map `phi` (one merge:
  `2b.reg.inc.shift_2` → `2b.reg.-2.inc`), `compat` (by `decide`, node by node), and
  `halts_iff` via `halts_iff_of_sim`. `gen_lean.py` checks the table against
  `machines/pa_309.txt`.

## 2. The tape (`Sem.lean`, `Tape.lean`, `Frame.lean`, `DagCheck.lean`)

* `Sem.lean`: registers `R` (ten fields) and the big-step semantics `Ex dag c s o t`: running a
  child (a node or a leaf) from registers `s` ends with outcome `o` (`brk k`, `cnt k`, `halt`)
  at the bit that led into it. The node rules (`car`, `cdr`, `restart`) are exactly what
  `6.break.k`/`6.continue.k` do to the program counter: a car's `brk (k+1)` is its parent's
  `brk k`, a cdr's `cnt (k+1)` its parent's `cnt k`, and a parent whose outcome would be `cnt 0`
  runs again.
* `Tape.lean`: the register file `rcells a rs` (the -1 register of `a` ones, then blocks
  `0 1^(v+1)`), and phase 2 of a register operation: the chain (`chainI`, `chainD`), `inc`
  (`incOp`, the blocks right of it shifted right by `ishift`), a successful `decnz` (`decOpPos`:
  the blocks shifted left by `dscan`/`dshift`, a new zero register at the end), a failed one
  (`decOpZero`), and the return to the `00` before the -1 register (`ret0`, `ret1` over `Sep1`
  lists). `phase2Inc`, `phase2DecPos`, `phase2DecZero` put them together.
* `Frame.lean`: the program counter `pc q` (root bits, main's entry bit, the path `q`).
  `disp_run`: dispatch counts zeros leftwards and finds the first cell when every run is at
  most 6 (`DOK`). `walk_run`, `root_run`: the walk down the DAG. `phase1`: the marker, the
  extended -1 register, dispatch. `cleanup`: `6.break.0` on a 0 bit, the -1 register restored.
  `cnt0_run`: `6.continue.0`. `leafRun` composes phase 1, the walk back and phase 2.
  `DagOK` lists what the DAG must satisfy (leaf kinds, zero runs, depth); `Inv` follows a
  path. `sim`: by induction on `Ex`, every outcome of a node is reached on the tape
  (`SimFrom`). `main_step1`, `main_halt`: one pass through main.
* `DagCheck.lean`: `dagOK` checks `DagOK` for the program's DAG (`decide` over 229 nodes) with
  `G = 3824`, the cell of the -1 register.

## 3. The program (`Prog.lean`, `Nodes.lean`, `Clean.lean`, `Abs.lean`, `Iter.lean`)

* `Prog.lean`: lemmas for the shapes TMBuilder makes: sequences (`ex_seq`), `while` loops
  (`ex_while`, with `loopN`), zeroing loops (`ex_zero`), tests (`ex_if`, `ex_test`), `if_eq`'s
  lockstep loop (`ex_lockstep`), the halt test (`ex_haltTest`, `ex_ifHalt`, `ex_seqH`), and the
  closed forms of moving loops (`loopN_inc`, `loopN_inc2`).
* `Nodes.lean` (generated by `gen_nodes.py`): for every node its effect `f<i>` and outcome, and
  the proof `e<i>` from the shape lemmas; `f<i>_eq` closed forms for moving loops.
* `Clean.lean`: `unpair`'s loop body is one step of Cantor's order (`f28_eq`), so its loop leaves
  `unpair(n)` (`f74_eq`, `f22_eq`); `pair`'s loop adds `T(a + b) + a` (`f52_eq`); `select`,
  `cons` and the pop as register updates.
* `Abs.lean`: between subroutines the scratch registers are zero and `wffstack` is a stack
  `stk` on a base (`A`, `enc`, `A.emb`). One lemma per subroutine: push, `par1/2/3`, `cons`,
  `select`, `drop`, the pops, the reload, the decoding steps, B6a's check group, DET's
  comparison, GEN, DET, the halt test (`*_emb`).
* `Iter.lean` (generated by `gen_iter.py`): main's 488 operations as `A.iter` (decoding, `v_0`,
  twelve candidate functions, GEN, DET); `main_emb`: node 0 computes it, then the halt test.

## 4. The proof search (`Pair.lean`, `Code.lean`, `Cand.lean`, `Step.lean`, `Search.lean`)

* `Pair.lean`: Cantor pairing `pair`, `unpair` (by successor steps, `nextP`), `unpair_pair`.
* `Code.lean`: formula codes (`eqC` … `allC`), `code`, `decode` (a tag above 4 reads as
  `v0 = v0`), `decode_code`.
* `Cand.lean` (generated by `gen_cand.py`): each candidate's code in its machine form
  (`axE` … `axB6a`) and `candX_eq`: its operations keep that code.
* `Step.lean`: `S.step`, one iteration of `pa/ref.py`'s `iterate_tail` (`decStep`, `kept`,
  `nextWs`); `iter_eq`: `A.iter` computes it.
* `Search.lean`:
  * Soundness: `cand_sound` (every candidate decodes to a theorem of T; E and B4 by `e_swap`
    and `perm`; B6a with a failed side condition is `v0 = v0`), `eq00` (`⊢ v0 = v0`), and
    `good_step` (`topwff` and every stack entry stay theorems).
  * Completeness: `axiom_M` (T's axioms derive from the candidates), `rpn` (a derivation is a
    list of steps that leaves the theorem in `topwff`), `steps_listCode` and `reach_code` (the
    search runs every list of steps).
  * `search_iff`: some iteration keeps `v0 ∈ v0` iff T proves it.

## 5. Logic (`Luk.lean`, `Logic.lean`)

* `Luk.lean` (generated by `gen_logic.py` from `cd_proofs.txt`, found by `cd_search.py`):
  condensed-detachment derivations in Łukasiewicz's system B1–B3. They give identity,
  contraction, `φ ∧ ψ → φ`, permutation of antecedents and contraposition (52 steps).
* `Logic.lean`: `Prov Ax` for any axiom set, `provable_iff`, the derived rules (`syl`,
  `perm_r`, `contra_r`, `and_congr_left`), and with B4 `all_congr`, `ex_congr`; `e_swap`: E with
  its first two antecedents swapped is equivalent to E.

## 6. The boot (`Boot1.lean`, `Boot2.lean`)

* `Boot1.lean`: the 5-state counter. `Sw k b X` is a sweep start (`0 0 (10)^k 1^b X`),
  `Big a t Z` a round start. `sweep` (three ones become four pairs: `gadget`, `scanDE`, the turn,
  `scanBD`), `sweeps`, `bigSw`, `endZero` (`scanAC`: the pairs become the next block), `sw_merge`
  (one one left), `endTwo` (two left: `3.prooflist.inc`), `init1`, and `boot1`: seven rounds
  with blocks 4, 10, 26, 76, 202, 538, 1434.
* `Boot2.lean`: `phase2IncEmpty` and `firstOp` finish boot1's operation (register 0 is created).
  `pcB m` is boot2's program counter `1 0 (10)^m 1 1`, with `walkB` (the root and
  `0b.boot2.0/1/2`). `incOpB` and `decOpB`/`decOpB0` are one pair each (phase 1, the walk, phase
  2, the break, the cleanup); `loopB` does 1908 pairs, and `boot` reaches main with 1909 zero
  registers.

## Putting it together

`Run.lean`: `aOf σ` is the register file at the start of an iteration. `pass` makes one pass
through main one `S.step`, halting iff the kept theorem is 1. `from_main`: from main's start the
machine halts iff T proves `v0 ∈ v0`:

* (→) by `not_halts_of_progress` over the iteration starts (each pass takes at least one step);
* (←) by passing up to the first iteration that keeps `v0 ∈ v0`.

`Main.lean`: `boot` reaches main's start (`start_main`), so `halts_iff` holds for the compiled
machine, and `haltAt_of` gives the halting configuration for the transfer to `M309`.
