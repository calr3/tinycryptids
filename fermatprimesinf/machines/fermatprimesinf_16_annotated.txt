; ============================================================================
; A 16-state, 2-symbol BEEPING Turing machine that QUASIHALTS IFF THERE ARE
; ONLY FINITELY MANY FERMAT PRIMES.
;
; THE BEEP is the transition of state G0 reading 0 (marked BEEP below).
; Started on a blank tape in the first state, the machine never halts, and it
; takes the beep transition exactly once for every Fermat prime 2^(2^n) + 1,
; in increasing order: 3, 5, 17, 257, 65537, ...
; So it beeps infinitely often iff there are infinitely many Fermat primes,
; and it quasihalts (beeps only finitely often) iff there are finitely many.
; Lean proof: lean/TinyCryptids/FermatPrimesInf/M16.lean,
; theorem TM.FermatPrimesInf.M16.quasihalts_iff (and never_halts).
; ============================================================================
;
; HOW TO READ THIS FILE
;   The machine is the 17-state design of build.py / fermatprimesinf.txt with
;   states merged. States are merged only when their defined transitions
;   agree, and no state that reads 0 joins the beep state, so the beep
;   transition is taken exactly where the design takes it. Each state below
;   plays one or more ROLES of the design (its name joins them); each
;   transition line is tagged [role] with the role(s) that use it. A '-' line
;   is never used.
;
; THE IDEA
;   A prime 2^k + 1 has k a power of 2, so the Fermat primes are the primes m
;   with m - 1 a power of 2. For odd m >= 5 these are the m such that no odd d
;   with 3 <= d <= m - 2 divides m or m - 1 (no odd divisor of m: m is prime;
;   no odd divisor >= 3 of m - 1: m - 1 is a power of 2). The machine tests
;   m = 5, 7, 9, ... in turn, each with d = 3, 5, 7, ...; one mod walk per d
;   tests both m and m - 1. When every d has passed, it beeps. (The start
;   beeps for m = 3.)
;
; TAPE LAYOUT (blank left of D and right of R)
;
;      D 0 R
;
;   D: d cells, all 1 except a HOLE (a single 0) at cell c: a counter mod d.
;      Before a walk the hole is on cell 0, the blank left of D's d - 1 ones.
;   one 0: the separator.
;   R: r cells, d + r = m - 1; during the mod walk a hole moves right in it.
;   Holes are found by scanners that count zeros: from one block, pass the
;   separator, stop at the next 0. A hole may sit next to the separator.
;
; ALGORITHM (candidate m, divisor d)
;   walk     D's hole starts on cell 0. r times: make the next cell of R the
;            R hole (R's cell 0 first), scan left to D's hole and move it one
;            cell right (from the last cell back to cell 0), scan right to R's
;            hole and fill it. D's hole ends on cell c = (m - 1) mod d:
;            d | m iff c = d - 1, d | m - 1 iff c = 0.
;   end      erase R's last cell (r := r - 1), scan left to the separator and
;            fill it. Read D's last cell: the hole means d | m (FAIL).
;            Otherwise erase D's cells leftwards to the hole and read the cell
;            past it: the blank left of D means c = 0, d | m - 1 (FAIL).
;   shift    d passed: refill the erased cells; the old separator becomes a
;            cell of D and R's cell 0 the new separator; the blank left of D
;            is the next hole: d := d + 2, r := r - 2. R empty: d = m - 2 was
;            the last odd d, every d passed: BEEP.
;   rebuild  FAIL or after the beep: one block of m - 1 ones. Write 1 1 at its
;            left end and the separator after them: candidate m + 2, d = 3.
;   start    1 1 and G0 on a blank: the beep for m = 3, then the rebuild.
; ============================================================================

blank_symbol: 0


; ---------- START (the rebuild's scan to the left end) ------------------

; C4     rebuild: run left to the blank before the block, write a 1 (H1 writes another)
start_C4
    0 1 L H1                   ; [C4]
    1 1 L start_C4             ; [C4]

; ---------- WALK: trial division of m = d + r + 1 by d ------------------

; B2     make R's hole here and scan left to D's hole (Y1); 0: past R's end, the walk is over (E)
B2
    0 0 L E                    ; [B2]
    1 0 L Y1                   ; [B2]
; Y1     scan left to the separator, then to D's hole (Y2)
Y1
    0 0 L Y2                   ; [Y1]
    1 1 L Y1                   ; [Y1]
; Y2     scan left to D's hole, fill it, step right (A2)
Y2
    0 1 R A2_W2                ; [Y2]
    1 1 L Y2                   ; [Y2]
; A2     advance D's hole: the new hole here, then to R's hole (Z1); 0: the separator, wrap (W1)
; W2     wrap: the new hole on D's cell 0, then to R's hole (Z1)
A2_W2
    0 0 L W1                   ; [A2]
    1 0 R Z1                   ; [A2, W2]
; W1     wrap: run left to the blank before D
W1
    0 0 R A2_W2                ; [W1]
    1 1 L W1                   ; [W1]
; Z1     scan right to the separator, then to R's hole (Z2)
Z1
    0 0 R Z2                   ; [Z1]
    1 1 R Z1                   ; [Z1]
; Z2     scan right to R's hole (the 0 after the separator), fill it, step right (B2)
Z2
    0 1 R B2                   ; [Z2]
    1 1 R Z2                   ; [Z2]

; ---------- END OF THE WALK and the CHECK: does d divide m or m - 1? ----

; E      erase R's last cell, then to the separator (V)
E
    -
    1 0 L V                    ; [E]
; V      scan left to the separator, fill it, check (X1)
V
    0 1 L X1                   ; [V]
    1 1 L V                    ; [V]
; X1     D's cell d - 1; 0: d | m, FAIL: fill it, rebuild (C4); 1: erase it (X)
X1
    0 1 R start_C4             ; [X1]
    1 0 L X                    ; [X1]
; X      erase D's cells leftwards to the hole, step past it (Q)
X
    0 0 L Q                    ; [X]
    1 0 L X                    ; [X]
; Q      the cell left of the hole; 0 (the blank: c = 0, d | m - 1): FAIL (HF); 1: d passed (H1)
Q
    0 0 R HF                   ; [Q]
    1 1 R H1                   ; [Q]
; HF     FAIL: refill the hole and the erased cells; the separator: rebuild (C4)
HF
    0 1 R HF                   ; [HF]
    1 1 L start_C4             ; [HF]

; ---------- SHIFT: d := d + 2, r := r - 2, the BEEP, and the REBUILD for m + 2 

; H1     refill erased cells going right; 1: the old separator, or the rebuild's 1 1 (G0)
H1
    0 1 R H1                   ; [H1]
    1 1 R G0                   ; [H1]
; G0     1: write the separator, start the walk (B2); 0: R is empty, every d passed: BEEP, then rebuild (C4)
G0
    0 0 L start_C4             ; [G0]   BEEP
    1 0 R B2                   ; [G0]
