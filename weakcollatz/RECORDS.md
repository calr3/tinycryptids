# Best machines so far

All machines are 2-symbol, start on a blank tape, and halt iff the Collatz map
has a cycle other than 1 → 4 → 2 → 1
(`∃ n k, 0 < n ∧ 0 < k ∧ iterate collatz k n = n ∧ n ≠ 1 ∧ n ≠ 2 ∧ n ≠ 4`).

## Searches for 13 states

A 13-state machine was looked for with the same tape (`C(M, v)`, head on cell 0 in the
start state at every macro step) and the same macro steps, checked on every `C(M, v)` with
`M ≤ 7` (first return to the start state on cell 0, within twice the 14-state machine's steps
and 3 cells of the block). Nothing was found:

* deleting any state of the 14-state machine, sending its incoming transitions to any other
  state, and changing up to two further transitions (write, move, next state or halt):
  about 150 million machines, none passes;
* the same with up to three changed transitions: about 62 billion machines, none passes.
* SAT synthesis of the whole table from the macro tests, adding failing tests as they appear
  (counterexample-guided), was tried for 13 states but did not finish in about 40 minutes.

These are not proofs that 13 is impossible: another tape layout or round structure could do
better.
