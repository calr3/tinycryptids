# v1: a Turing machine for the weak Collatz conjecture

*Superseded by the 14-state machine in `../` (`TM.WeakCollatz.halts_iff`). Kept with its
proof (`TM.WeakCollatzV1.*`) as an earlier design.*

**`machines/weakcollatz_23.txt`, a 23-state, 2-symbol Turing machine**
(named-state format, see `../../tools/tm.py`). Started on a blank tape, it **halts iff
the Collatz map has a cycle other than 1 → 4 → 2 → 1**, i.e. iff the weak Collatz
conjecture is false. Lean proves this (`TM.WeakCollatzV1.M23.halts_iff`):

    Halts M23.delta2 M23.start2 ↔
      ∃ n k, 0 < n ∧ 0 < k ∧ iterate collatz k n = n ∧ n ≠ 1 ∧ n ≠ 2 ∧ n ≠ 4

where `collatz x` is `x / 2` for even `x` and `3x + 1` for odd `x`
(`TinyCryptids.collatz`, `../../lean/TinyCryptids/Defs.lean`). `RECORDS.md` lists every
machine with its state count and Lean theorem. `PROOF.md` walks through the proof in plain words.

(The full Collatz conjecture also says no orbit diverges, which no machine can
search for this way. The weak version, "no other cycle", is the part that a
counterexample search can settle.)

The 23-state machine is obtained in two stages:

1. `weakcollatz.txt` is the readable **25-state design**, generated by `build.py`.
   The Lean proof is written for this machine (`TM.WeakCollatzV1.halts_iff`).
2. `minimize.py` merges states of the design that never disagree on a transition
   the run uses (an exact SAT search), giving 23 states; 22 is unsatisfiable.
   `gen_reduced_lean.py` carries the theorem over. `machines/weakcollatz_23_annotated.txt`
   is the same machine with each state named after its roles in the design.

## The search: no dovetailing needed

A naive search would have to dovetail over pairs (start, number of steps),
because an orbit might diverge. Instead the machine looks for each cycle at its
**largest element**:

    for n = 1, 2, 3, ...:
        x := n
        repeat x := C(x) until x >= n or x = 1
        if x = n: HALT

* If a nontrivial cycle exists, take the cycle whose largest element `M` is
  smallest. From `M` the orbit stays in `[2, M]` and returns to `M`, so round `M`
  halts.
* A round can only run forever if its orbit stays in `[2, n−1]` forever. Then it
  falls into a nontrivial cycle below `n`, whose round already halted. More
  precisely (`reach_cond` in `Spec.lean`, by induction on `n`, no pigeonhole
  argument): if no nontrivial cycle lies in `[2, n)`, every orbit from `[1, n)`
  reaches 1 or a value `≥ n`.
* Round `n` never halts on the trivial cycle: from 1, 2 or 4 the orbit reaches 1
  (or 4 > 1) before it returns.

## How it works

The whole tape is **one block of n+2 cells** (cells 0 .. n+1), all 1 except a
**hole** H (a single 0) at cell x, with 1 ≤ x ≤ n. So n is the block length, x
is a position in it, and "x > n" is "H ran off the block". Cells 0 and n+1 stay 1.

A step starts at H: run left to cell 0 and walk back to H, counting parity.

* **x even.** A second hole G walks from x−1 to the left end, two cells per
  round trip, while H moves left one cell per round trip: H ends at x/2. If
  x/2 = 1 the round is over.
* **x odd.** G takes the old hole (x) and H moves to x+1. G walks to the left
  end, one cell per round trip, while H moves right two cells: H ends at
  x+1+2x = 3x+1. If H runs off the block (3x+1 > n), the round is over; if H
  stops at cell n (3x+1 = n), the machine halts.
* **Next round.** Fill G if it is still in the block, add one cell at the right
  end, and put H on cell n+1, the new last value cell: x = n+1.

Navigation is just "run over 1s to the next 0": between steps the block has one
hole, during a step two, and the region between them is all 1s.

The seed writes cell 0 and continues as after an aborted round 0, which grows the
block to `1 0 1`: round 1.

State budget of the 25-state design: seed 1, step start and parity 4, even 8,
odd 6, check 3, next round 3.

## Files and checks

* `build.py` generates the design (`python3 build.py weakcollatz.txt`).
* `test_e2e.py`: at every step (the parity branch at H), the whole tape is
  compared with the reference (n, x) sequence, for rounds 1 .. 294. A test variant
  without the "x = 1" stop finds the trivial cycle and halts in round 4. The
  machine runs past 10⁸ steps.
* Shared tools in `../../tools/`: `tm.py` parses the format and converts it to
  bbchallenge standard text (`python3 ../../tools/tm.py machines/weakcollatz_23.txt`);
  `sim.c` is a fast simulator (`gcc -O2 -o ../../tools/sim ../../tools/sim.c`);
  `same_run.py A B k` checks that two machines have identical tapes after
  10^3 .. 10^k steps (design vs. 23 states: up to 10⁸); `minimize.py` (exact SAT)
  and `greedy_merge.py` merge states; `leangen.py` writes the generated Lean files.
* `gen_lean.py` writes `../../lean/TinyCryptids/WeakCollatzV1/Machine.lean` (the design);
  `gen_reduced_lean.py machines/weakcollatz_23.txt M23` writes `M23.lean`;
  `annotate.py`: the readable listing.
* The proof: `../../lean/TinyCryptids/WeakCollatzV1/` (see `../../lean/README.md`).
