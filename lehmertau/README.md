# A Turing machine for Lehmer's conjecture on Ramanujan's τ

**Current best: `machines/lehmertau_295.txt`, a 295-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff Lehmer's
conjecture is false**, i.e. iff `τ(n) = 0` for some `n ≥ 1`. Lean proves this
(`TM.LehmerTau.M295.halts_iff`):

    Halts M295.delta2 M295.start2 ↔ ∃ n, 1 ≤ n ∧ tau756 n = 0

where `tau756 n = 65 σ₁₁(n) + 691 σ₅(n) − 174132 Σ_{i=1}^{n−1} σ₅(i) σ₅(n−i)` (an integer) and
`σ_k(n) = Σ_{d ∣ n} d^k` (`../lean/TinyCryptids/Defs.lean`). This is `756 τ(n)` by the classical
identity; core Lean has no modular forms, so the identity itself is not formalized (`Defs.lean`
checks `τ(1) = 1`, `τ(2) = −24`, `τ(3) = 252`). `RECORDS.md` lists the machines, and
`PROOF.md` walks through the proof in plain words.

The 295-state machine is obtained in two stages:

1. `lehmertau.txt` is the readable **481-state design**, generated by `build.py`. The Lean
   proof is written for this machine (`TM.LehmerTau.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition the
   run uses (an exact SAT search). `gen_reduced_lean.py` carries the theorem over, and
   `machines/lehmertau_295_annotated.txt` is the same machine with each state named after its
   roles in the design.

## The search

For `n = 2, 3, …` (`τ(1) = 1`) the machine builds two unary numbers

    P = Σ_{i=1}^{n−1} Σ_{d ∣ i} Σ_{e ∣ n−i} 252 · 691 · d⁵ e⁵ = 174132 Σ σ₅(i) σ₅(n−i)
    M = Σ_{d ∣ n} (691 d⁵ + 65 d¹¹)                         = 691 σ₅(n) + 65 σ₁₁(n)

and halts iff `P = M`. Every product is counted by one routine, an odometer: the factors are
blocks at the right end of the tape, counted through like the digits of a mixed-radix counter,
and each count appends one cell to the accumulator at the far left. The powers are copies of
`d` and `e`; the constants are blocks that take part in a run as extra digits when switched on.

## How it works

The tape, left to right (blocks of 1s, separators `0 0`; a hole is a single 0 in a block):

    [M] 00 P 00 K65 00 K252 00 K691 00 X 00 Z 00 D 00 Rd 00 E 00 Re 00 S0 00 V…

* **P**, **M**: `v + 1` cells for the value `v`; M exists only in the L phase.
* **K65, K252, K691**: `f + 2` cells. A switched-on constant has a hole (at rest at cell 1),
  which is its digit in a run. R phase: K252 and K691 on; L phase: K691, then K65.
* **X**: the copy counter, 13 cells (a hole at cell `h` makes `12 − h` copies). **Z**: one cell.
* **D, Rd** and **E, Re**: two frames for the mod walk of `../legendre/`: `d + rd = i` and
  `e + re = n − i`; the hole of D (or E) is the residue, and the walk stops at each divisor.
  In the L phase (`i = n`) E and Re are a dummy (4 and 1 cells), which tells the phases apart.
* **S0**: two cells, the start of the copies **V…**.

**R phase**, `i = 1 … n−1`: the walk on D stops at each `d ∣ i`, then a walk on E at each
`e ∣ n − i`; there E is copied five times and D five times, and a run over the ten copies and
K252, K691 adds `252·691·d⁵e⁵` to P. The copies are erased, and the walk goes on. After the last
`d`, Re gives a cell to Rd (`i + 1`). **L phase**, `i = n`: at each `d ∣ n`, D is copied five times
and a run with K691 adds `691 d⁵` to M; K65 and K691 are flipped, D is copied eleven times and a
run with K65 adds `65 d¹¹`; they are flipped back. **End of n**: the frames are reset (Rd's
cells move to Re), M and P are compared one cell at a time at the far left (**halt** if they run
out together), M is erased, P set to 0, K252 switched on.

The **seed** writes the frames and the three constants as binary counters (bits, most
significant first, each after a marker 1); each counter, last first, is drained into a new block
at the far left one cell per decrement and then erased. Then P is created and the walk starts
at `n = 2`.

State budget of the 481-state design: mod walk 40, unshift 16, divisor dispatch 37, copy 52,
run 37, after a run (erase, flips) 51, loop ends and the next `i` 64, end of `n` and compare 50,
seed 134 (97 of them write the start word).

|------|----------|

`../lean/TinyCryptids/LehmerTau/` (see `../lean/README.md`).
