; ============================================================================
; A 295-state, 2-symbol Turing machine that HALTS IFF LEHMER'S CONJECTURE ON
; RAMANUJAN'S TAU FUNCTION IS FALSE, i.e. iff tau(n) = 0 for some n >= 1.
; Start on a blank tape in the first state. A transition to `halt` halts.
; Lean proof: lean/TinyCryptids/LehmerTau/M295.lean,
; theorem TM.LehmerTau.M295.halts_iff.
; ============================================================================
;
; HOW TO READ THIS FILE
;   The machine is the 481-state design of build.py / lehmertau.txt with
;   states merged. States are merged only when their defined transitions agree,
;   so each state below plays one or more ROLES of the design (its name joins
;   them). Each transition line is tagged [role] with the role(s) that use it.
;   A '-' line is never used. The seed roles run once at the start and only
;   ever read 0, so most of them double as a step of some other routine.
;
; THE SEARCH
;   756 tau(n) = 65 s11(n) + 691 s5(n) - 174132 sum_{i<n} s5(i) s5(n-i), with
;   s_k the divisor power sums. For n = 2, 3, ... the machine builds
;       P = sum_{i=1}^{n-1} sum_{d|i} sum_{e|n-i} 252 * 691 * d^5 e^5
;       M = sum_{d|n} (691 d^5 + 65 d^11)
;   and HALTS iff P = M (tau(1) = 1 is skipped).
;
; TAPE LAYOUT (blocks of 1s separated by 00; a hole is a single 0 in a block):
;
;      [M] 00 P 00 K65 00 K252 00 K691 00 X 00 Z 00 D 00 Rd 00 E 00 Re 00 S0 00 V..
;
;   P, M  accumulators (v + 1 cells); M exists only in the L phase (i = n)
;   K65, K252, K691  the constants (f + 2 cells); an ACTIVE one has a hole
;      (at rest at cell 1) and is a digit of the run
;   X  copy counter (13 cells); Z one cell (tells D from E)
;   D, Rd  frame for d + rd = i;  E, Re  frame for e + re = n - i (the mod
;      walk of legendre/: the hole of D or E is the residue). In the L phase
;      E and Re are a dummy: E' 4 cells, Re' 1 cell
;   S0  two cells; V..  the copies, the var digits of the run
;
; ALGORITHM
;   frames    the mod walk visits the divisors d of i (frame D), and inside
;             each the divisors e of n - i (frame E)
;   copy      a block (cursor at cell 1) is copied to the right end; X counts
;             the copies (5 for d, e; 11 for d^11)
;   run       an odometer over the var digits and the active K digits; every
;             count adds a cell to the leftmost block (P, or M)
;   R phase   for e | n-i: copy E x5, D x5, run with K252 and K691
;   L phase   for d | n: copy D x5, run with K691; flip; D x11 with K65; flip
;   end of n  E', Re' -> E, Re; Rd's cells move to Re; compare M and P one
;             cell at a time (HALT if equal); M erased, P = 0, K252 on
;   seed      writes the frames and the constants as binary counters, drains
;             each counter into a unary block at the far left
; ============================================================================
