# Lean proofs for every machine

One Lake project, Lean 4.15.0, core library only (no Mathlib).

    lake build                  # checks every proof
    lake env lean Check.lean    # prints every main theorem and the axioms it uses

Every main theorem depends only on `propext`, `Classical.choice` and `Quot.sound`.

## Layout

| Path | Contents |
|------|----------|
| `TinyCryptids/Core/Sys.lean` | Deterministic step systems: `run`, `Reach`, `Reach1`, `Halts`, `not_halts_of_progress` |
| `TinyCryptids/Core/Basic.lean` | **The machine model** shared by every machine: 2 symbols, stream tapes, `step`; `TM.Halts δ c` is `Sys.Halts (step δ) c`. Also `sim_run` and `halts_iff_of_sim` (a merged machine halts iff the original does) |
| `TinyCryptids/Core/Lemmas.lean` | Single steps, scans, `Clean` words and the 2-state hole parsers |
| `TinyCryptids/Defs.lean` | **The definitions used in the theorem statements**, namespace `TinyCryptids`: `iterate`, `collatz` |
| `TinyCryptids/<Machine>/` | One hand-designed machine per folder, namespace `TM.<Machine>` |
| `Check.lean` | Every main theorem with `#check` and `#print axioms` |

Each hand-designed machine folder has the same shape:

| File | Contents |
|------|----------|
| `Machine.lean` | The design, generated by the folder's `gen_lean.py` from `<name>.txt`: `St`, `delta`, `start` |
| `Tac.lean` | One-step tactics `gR`/`gL`, scans `sRn`/`sLn`, … for this machine's `delta` |
| `Spec.lean` | Arithmetic the proof needs |
| other files | One lemma per routine, `Rch ⟨entry, tape⟩ ⟨exit, tape'⟩` |
| `Main.lean` | The main theorem for the design, `TM.<Machine>.halts_iff` |
| `M<k>.lean` | Generated by `gen_reduced_lean.py`: the `k`-state merged machine `delta2`, the state map `phi`, `compat`, and `TM.<Machine>.M<k>.halts_iff` via `halts_iff_of_sim` |

## Main theorems

| Theorem | Statement (`Halts delta start ↔ …`) |
|---------|-----------|
| `TM.WeakCollatz.halts_iff`, `M23` | `∃ n k, 0 < n ∧ 0 < k ∧ iterate collatz k n = n ∧ n ≠ 1 ∧ n ≠ 2 ∧ n ≠ 4` |

## Proof outlines

**Weak Collatz** (`TinyCryptids/WeakCollatz`). One block of `n + 2` cells with the value `x`
as a hole. `Step`: the parity walk, the even loop (`EL`: H to `x/2`), the odd loop (`OL`:
H to `3x + 1`, overflow when it runs off the block), the check, the next round (`RS`);
`step_cases` and `round_run` (a round stops at the first `i` with `Cond n (C^(i+1) n)`).
`Spec`: rounds stop when no nontrivial cycle lies below `n` (`reach_cond`, by induction on
`n`), do not return to `n` without a cycle (`round_no_return`), and a cycle gives a least
`M` whose round halts (`exists_top`).

(→) by `not_halts_of_progress` over the round starts (each round strictly reaches the
next when there is no counterexample); (←) by iterating the round up to the
counterexample, which reaches the explicit halting state.
