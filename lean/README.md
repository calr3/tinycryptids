# Lean proofs for every machine

One Lake project, Lean 4.15.0, core library only (no Mathlib).

    lake build                  # checks every proof
    lake env lean Check.lean    # prints every main theorem and the axioms it uses

Every main theorem depends only on `propext`, `Classical.choice` and `Quot.sound`.

## Layout

| Path | Contents |
|------|----------|
| `TinyCryptids/Core/Sys.lean` | Deterministic step systems: `run`, `Reach`, `Reach1`, `Halts`, `not_halts_of_progress` |
| `TinyCryptids/Core/Basic.lean` | **The machine model** shared by every machine: 2 symbols, stream tapes, `step`; `TM.Halts δ c` is `Sys.Halts (step δ) c`. Also `sim_run` and `halts_iff_of_sim` (a merged machine halts iff the original does) |
| `TinyCryptids/Core/Lemmas.lean` | Single steps, scans, `Clean` words and the 2-state hole parsers |
| `TinyCryptids/Core/Routines.lean` | Generic routines: cyclic advance of a hole (`Dadv`, `DadvL`, `DW`), parsers in `ones` form |
| `TinyCryptids/Core/Beep.lean` | **Beeping machines**: `BeepsAt δ qb bb c n` (step `n + 1` is the beep transition, state `qb` reading `bb`), `QuasiHalts` (finitely many beeps), runs of a sub-machine (`run_sub`), `quasihalts_of_sub` (the machine without its beep never halts ⟹ no more beeps), `quasihalts_iff_of_sim` (a merged machine beeps at the same steps) |
| `TinyCryptids/Core/BeepBoop.lean` | **Beeping booping machines** (Bram Cohen): `beepsBetween`, `RepeatsForever δ qb bb qo bo c` (some number of beeps between consecutive boops occurs infinitely often), `repeatsForever_of_segments` (a run cut into segments with no event or `v` beeps and a boop), `Trace` and `Trace.evs` (the events of event-free runs joined by single beep and boop steps), `repeatsForever_iff_of_sim` |
| `TinyCryptids/Core/Mirror.lean` | The mirror image of a machine (`mirror`, `Cfg.mir`): `Reach.mir`, `Reach.of_mir`, `Reach.embed` (a routine proved once runs mirrored in a bigger machine) |
| `TinyCryptids/Core/Basic3.lean` | The same model with 3 symbols (`TM3`: `Sym` = `s0 s1 s2`, `s0` blank) and its single steps and scans, for `weakcollatz/sym3/` |
| `TinyCryptids/Core/Multi.lean` | Machines with any number of symbols (namespace `TMK`): symbols `Nat` (0 blank), stream tapes `Nat → Nat`, `step`, `Halts`, `halts_iff_of_sim`; used by the 6-symbol Goldbach machine (`goldbach/`) and the 10-symbol PA machine (`pa_nsymbols/`) |
| `TinyCryptids/Core/BeepK.lean` | `Beep.lean`'s `BeepsAt`, `QuasiHalts`, `run_sub` and `quasihalts_of_sub` for the machines of `Multi.lean`; used by the 4-symbol twin prime machine (`twinprimes/sym4/`) |
| `TinyCryptids/Defs.lean` | **The definitions used in the theorem statements**, namespace `TinyCryptids`: `iterate`, `collatz`, `Prime`, `primeCount`, `primesBelow`, `properDivSum`, `fact`, `leftFact`, `fib`, `choose`, `totient`, `sigma`, `tau756`, `rep`, `powSum`, `digits3`, `rev10`, `hasZeroDigit`, `gilbreathRow`, `IsBarker`, `Amicable`, `InfinitelyManyAmicable`, `GoldbachConjecture`, `TwinPrimeConjecture`, `MersennePrimeConjecture`, `SophieGermainPrime`, `FinitelyManySophieGermainPrimes`, `InfinitelyManyFermatPrimes`, `radBelow`, `rad`, `ABCConjecture`, `PillaiConjecture`, and the theory T of the PA machines (`Wff`, `Wff.Axiom`, `Wff.Provable`); also `prime_iff_dvd` |
| `TinyCryptids/<Machine>/` | One hand-designed machine per folder, namespace `TM.<Machine>` |
| `TinyCryptids/PA/`, `TinyCryptids/PAK/` | The compiled PA machines: 2 symbols (`TM.PA`) and 10 symbols (`TMK.PA`); see the outlines below |
| `Check.lean` | Every main theorem with `#check` and `#print axioms` |

Each hand-designed machine folder has the same shape:

| File | Contents |
|------|----------|
| `Machine.lean` | The design, generated by the folder's `gen_lean.py` from `<name>.txt`: `St`, `delta`, `start` |
| `Tac.lean` | One-step tactics `gR`/`gL`, scans `sRn`/`sLn`, … for this machine's `delta` |
| `Spec.lean` | Arithmetic the proof needs |
| other files | One lemma per routine, `Rch ⟨entry, tape⟩ ⟨exit, tape'⟩` |
| `Main.lean` | The main theorem for the design, `TM.<Machine>.halts_iff` |
| `M<k>.lean` | Generated by `gen_reduced_lean.py`: the `k`-state merged machine `delta2`, the state map `phi`, `compat`, and `TM.<Machine>.M<k>.halts_iff` via `halts_iff_of_sim` |

## Proof outlines

**Weak Collatz** (`TinyCryptids/WeakCollatz`), the 14-state machine. One block with the
value `v` as a hole at cell `v − 1` (`CS M v`), iterating the shortcut map `tc`. `Step`: going
home (`go_home`), `v = 1` (`step_one`), the halving loop (`HL`: a marker from cell 0 meets the
hole; for even `v` the marker is the result, `hl_even`, `step_even`), the odd loop (`OL`: the
marker walks back while the hole moves two cells, `hl_odd`, `ol_over`, `ol_end`, `step_odd`),
`step_cases` and `round_run`. `Spec`: rounds stop when no nontrivial cycle lies below `n`
(`reach_cond`, by induction on `n`), do not return to `n` without a cycle (`round_no_return`),
and a cycle gives a least `M` whose round halts (`exists_top`). `Cycle`: `tc`-cycles through
`n ≥ 3` are exactly `collatz`-cycles outside `{1, 2, 4}` (`counter_iff`).
`TinyCryptids/WeakCollatz16` is the same proof for the given 16-state machine (marker from
cell 1, `cut` and `grow`), sharing `Spec` and `Cycle`. `TinyCryptids/WeakCollatzV1` is the
earlier 25/23-state machine: parity walk, `EL`/`OL` loops, the same `Spec` for `collatz`.
`TinyCryptids/WeakCollatz3` is the 10-state, 3-symbol machine (`TM3`: `Core/Basic3.lean`, the
model of `Core/Basic.lean` with symbols `s0 s1 s2`). The end of the block is a 2 that is also
the hole of `v = M` (`RS`, `HE`, `OE`); `ol_run` sorts the odd loop's outcomes. It shares
`WeakCollatz/Spec` and `Cycle`.

**Goldbach with 6 symbols** (`TinyCryptids/Goldbach`, see `../goldbach/README.md`). `Machine.lean`
and `M10.lean` are generated by `goldbach/gen_lean.py`. `Tape`: list-shaped configurations, `CL`
(the head on `L 0`), `walkR`/`walkL`, `runR`/`runL`. `Test`: the in-place trial division of one
block between any delimiters: `T`, `Zc`, `Cx`, `zstep_more`, `zstep_wrap`, `zend_more`,
`zend_div`, `zig` (a round, by the D marks modulo `d`), `test`. `Main`: `Pc p Q`, `pair_step`,
`grow`, `p_comp`, `q_comp`, `shift`, `boot` (by `decide` on finite tapes, as `PAK/Boot`); (→) by
`not_halts_of_progress`, (←) by `halt_from` and `haltAt_of`.

**Fermat** (`TinyCryptids/Fermat`), the 127-state design and the 90-state merged machine.
`Copy`: the copy loop with a cursor of its own on R (R's hole is the single 0 after A; Q after
another single 0). `Blk`, `Pow`: power computation R := base^E with the base block marked by a
hole on its cell 1, a round that starts without a base hole, cursors allowed next to a
separator (`ParserL.find3`, `lg_find`), and the merge entered from the end of the base.
`NextBase`: the marker moves to the next base and R is added into A by filling the 0 between
them; a new `R = 1` is cut from the end. `Compare`: the zig-zag (`zz`, halt iff A has one cell
more than R) and `HaltAt`. `Tuple`: the setup (the next-base step from the anchor,
`ParserR.find3`), one tuple (`tuple_check`), the clear. `Enum`: one enumeration step.
`Nexcom`: the search order `nxt` (NEXCOM on compositions) reaches every valid tuple. `Main`:
the seed and the main loop; `M90` is generated by `gen_reduced_lean.py`.

**Twin primes** (`TinyCryptids/TwinPrimes`, beeping). Tape `D 0 R`, holes found by scanners that
count zeros. Every routine is proved for `deltaNB` (the design without its beep transition,
generated next to `delta`; `deltaNB_sub`), so its runs never beep; only `beep_step` uses
`delta`. `Round`: `W d r c k` (the mod walk with `k` steps left), `walk_core`, `walk_step`,
`walk` (D's hole ends on `(c + k) % d`), `check_fail` / `check_ok` (D's cells `d − 1, d − 2,
d − 3`), `shift_more` / `shift_beep` (`d + 1`, `r − 1`; R empty: `BeepCfg`), `rebuild`, `seed`.
`Spec`: `Good`, `fail_iff` (the hole on `d − 1` or `d − 3` iff `d ∣ m ∨ d ∣ m + 2`), `twin_iff`.
`Main`: `test` (induction on `r`), `cand_twin`, `cand_not`, `after_beep`, `cand_step`,
`reach_cs`; (→) a twin prime `p ≥ N + 3` beeps after step `N`; (←) `deltaNB` never halts from
`CS (N + 3)` (`not_halts_of_progress`), so `quasihalts_of_sub`. `M18` by
`quasihalts_iff_of_sim` with `excl`.
`TinyCryptids/TwinPrimes4` is the 10-state, 4-symbol machine (`TMK`, `Core/Multi.lean`; beeps
in `Core/BeepK.lean`). Tape `D R` with D's cells 3, R's cells 1 and a marker / cursor 2, so there
is no separator. `Round`: `walk_step`, `walk`, `zig` and `rebuild` (`reb`'s zigzag), `check_fail`,
`check_ok`, `zs_beep`, `start_beep`, `beep_step`, `after_beep` (the beep path makes candidate
`m + 3`). `Main`: `test`, `cand_twin`, `cand_not` (sharing `TwinPrimes/Spec`), `reach_cand`
(every `m ≥ 3` is a candidate or follows a twin prime candidate by 1 or 2), `twin_gap` (lesser
twin primes `q < p < q + 3` are 3 and 5) and `reach_twin`, then (→) and (←) as above.

**Fermat primes** (`TinyCryptids/FermatPrimes`). `../twinprimes`'s walk with odd `d` and odd
`m`, testing `m` and `m − 1`, halting. `Spec`: `odd_not_dvd_pow2`, `pow2_of_no_odd`,
`dvd_pow_odd_add_one`, `prime_pow_two_add_one` (`2^k + 1` prime ⟹ `k` a power of
2), `fp_iff'`, `prime_of_lt` and `prime_17`, `prime_257`, `prime_65537` (by `decide`), `fp_small`
(the passes in `[7, 65537]`), `fp_big_iff`. `Round`: the walk for any tail `F ::: Y`,
`check_last`, `check_first`, `check_ok`, `shift`, `rebuild`, `PassCfg`, `pass_more`, `pass_halt`,
`seed`. `Main`: `CS m g j` (the counter `j` cells away), `fail_iff`, `test`, `cand_pass`,
`cand_not`, `fails`, `reach_big` (5, 17, 257, 65537 leave one cell), `haltAt_of`; (→) by
`not_halts_of_progress` from `CS 65539`, (←) by `haltAt_of`.

**Fermat primes, infinitely many** (`TinyCryptids/FermatPrimesInf`, beeping). `../fermatprimes`'s
machine without the counter: every pass beeps. `Spec`: `fpi_iff` (the passes are unbounded iff
`InfinitelyManyFermatPrimes`); `Good`, `FP`, `fp_iff'` and `fail_iff` are imported from `FermatPrimes`.
`Round`: `W`, `walk_all`, `walk_end`, `shift`, `rebuild`, `beep_step`, `seed`, with
`../fermatprimes`'s `check_last`, `check_first` (joined in `check_fail`) and `check_ok`. `Main`:
`test`, `cand_fp`, `cand_not`, `after_beep`, `cand_step`, `reach_cs`, `never_halts`, `quasihalts_iff`,
`beeps_forever_iff`, as for Twin primes. `M16` by `quasihalts_iff_of_sim` with `excl`.

**Mersenne primes** (`TinyCryptids/Mersenne`, beeping). `../twinprimes`'s walk with odd `d` and
odd `m`: `Spec`: `Good` (`e ∤ m`, `e ∤ m + 1`), `MP`, `odd_not_dvd_pow2`, `pow2_of_no_odd`,
`mersenne_iff` (odd `m` is a Mersenne prime iff every odd `e ∈ [3, m)` is good), `mpc_iff`.
`Round`: `W d r c k` (`k` steps done, the R hole moving right; D's hole home on the blank left
of D), `walk_step`, `walk_all` (the hole ends on `r % d`), `walk_end` (erase R's last cell,
fill the separator), `alt` (`X1`/`X2` erase `2 i` cells), `ok_dance`, `check_ok`,
`check_fail`, `shift` (`d + 2`, `r − 2`), `rebuild`, `beep_step`, `seed` (the beep for `m = 3`).
`Main`: `fail_iff`, `test` (induction on `t`, `r = 2 t + 1`), `cand_mp`, `cand_not`,
`after_beep`, `cand_step`, `reach_cs`, `never_halts`, `quasihalts_iff` (as for twin primes),
`beeps_forever_iff`. `M14` by `quasihalts_iff_of_sim` with `excl`.

**Sophie Germain primes** (`TinyCryptids/SophieGermain`, beeping). `../mersenne`'s tape with D's
hole moving two cells per walk step. `Spec`: `Good` (`e ∤ n`, `e ∤ 2n + 1`), `sg_iff` (odd `n ≥ 5`
is a Sophie Germain prime iff every odd `e ∈ [3, n − 2]` is good). `Walk`: `W`, `walk_step` (three
cases: no wrap, `d − 2 → 0`, `d − 1 → 1`), `walk_all` (the hole ends on `2r % d`). `Round`:
`walk_end` (erase R's last cell, scan to the hole and fill it: `KC`), `check_ok1`, `check_ok`,
`check_fail`, `shift`, `rebuild` (the check run on the blanks left of the block), `beep_step`,
`seed`. `Main`: `mod_two_mul`, `fail_iff`, `check`, `test`, `cand_sg`, `cand_not`, `after_beep`,
