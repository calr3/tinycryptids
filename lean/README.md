# Lean proofs for every machine

One Lake project, Lean 4.15.0, core library only (no Mathlib).

    lake build                  # checks every proof
    lake env lean Check.lean    # prints every main theorem and the axioms it uses

Every main theorem depends only on `propext`, `Classical.choice` and `Quot.sound`.

## Layout

| Path | Contents |
|------|----------|
| `TinyCryptids/Core/Sys.lean` | Deterministic step systems: `run`, `Reach`, `Reach1`, `Halts`, `not_halts_of_progress` |
| `TinyCryptids/Core/Basic.lean` | **The machine model** shared by every machine: 2 symbols, stream tapes, `step`; `TM.Halts δ c` is `Sys.Halts (step δ) c`. Also `sim_run` and `halts_iff_of_sim` (a merged machine halts iff the original does) |
| `TinyCryptids/Core/Lemmas.lean` | Single steps, scans, `Clean` words and the 2-state hole parsers |
| `TinyCryptids/Core/Routines.lean` | Generic routines: cyclic advance of a hole (`Dadv`, `DadvL`, `DW`), parsers in `ones` form |
| `TinyCryptids/Core/Beep.lean` | **Beeping machines**: `BeepsAt δ qb bb c n` (step `n + 1` is the beep transition, state `qb` reading `bb`), `QuasiHalts` (finitely many beeps), runs of a sub-machine (`run_sub`), `quasihalts_of_sub` (the machine without its beep never halts ⟹ no more beeps), `quasihalts_iff_of_sim` (a merged machine beeps at the same steps) |
| `TinyCryptids/Core/BeepBoop.lean` | **Beeping booping machines** (Bram Cohen): `beepsBetween`, `RepeatsForever δ qb bb qo bo c` (some number of beeps between consecutive boops occurs infinitely often), `repeatsForever_of_segments` (a run cut into segments with no event or `v` beeps and a boop), `Trace` and `Trace.evs` (the events of event-free runs joined by single beep and boop steps), `repeatsForever_iff_of_sim` |
| `TinyCryptids/Core/Mirror.lean` | The mirror image of a machine (`mirror`, `Cfg.mir`): `Reach.mir`, `Reach.of_mir`, `Reach.embed` (a routine proved once runs mirrored in a bigger machine) |
| `TinyCryptids/Core/Basic3.lean` | The same model with 3 symbols (`TM3`: `Sym` = `s0 s1 s2`, `s0` blank) and its single steps and scans, for `weakcollatz/sym3/` |
| `TinyCryptids/Core/Multi.lean` | Machines with any number of symbols (namespace `TMK`): symbols `Nat` (0 blank), stream tapes `Nat → Nat`, `step`, `Halts`, `halts_iff_of_sim`; used by the 10-symbol PA machine (`pa_nsymbols/`) |
| `TinyCryptids/Core/BeepK.lean` | `Beep.lean`'s `BeepsAt`, `QuasiHalts`, `run_sub` and `quasihalts_of_sub` for the machines of `Multi.lean`; used by the 4-symbol twin prime machine (`twinprimes/sym4/`) |
| `TinyCryptids/Defs.lean` | **The definitions used in the theorem statements**, namespace `TinyCryptids`: `iterate`, `collatz`, `Prime`, `properDivSum`, `fact`, `leftFact`, `TwinPrimeConjecture`, `InfinitelyManyFermatPrimes`, `radBelow`, `rad`, `ABCConjecture`, and the theory T of the PA machines (`Wff`, `Wff.Axiom`, `Wff.Provable`); also `prime_iff_dvd` |
| `TinyCryptids/<Machine>/` | One hand-designed machine per folder, namespace `TM.<Machine>` |
| `TinyCryptids/PA/`, `TinyCryptids/PAK/` | The compiled PA machines: 2 symbols (`TM.PA`) and 10 symbols (`TMK.PA`); see the outlines below |
| `Check.lean` | Every main theorem with `#check` and `#print axioms` |

Each hand-designed machine folder has the same shape:

| File | Contents |
|------|----------|
| `Machine.lean` | The design, generated by the folder's `gen_lean.py` from `<name>.txt`: `St`, `delta`, `start` |
| `Tac.lean` | One-step tactics `gR`/`gL`, scans `sRn`/`sLn`, … for this machine's `delta` |
| `Spec.lean` | Arithmetic the proof needs |
| other files | One lemma per routine, `Rch ⟨entry, tape⟩ ⟨exit, tape'⟩` |
| `Main.lean` | The main theorem for the design, `TM.<Machine>.halts_iff` |
| `M<k>.lean` | Generated by `gen_reduced_lean.py`: the `k`-state merged machine `delta2`, the state map `phi`, `compat`, and `TM.<Machine>.M<k>.halts_iff` via `halts_iff_of_sim` |

## Main theorems

| Theorem | Statement (`Halts delta start ↔ …`) |
|---------|-----------|
| `TM.WeakCollatz.halts_iff`; `TM.WeakCollatz16.halts_iff` (m16); `TM.WeakCollatzV1.halts_iff`, `M23` (v1) | `∃ n k, 0 < n ∧ 0 < k ∧ iterate collatz k n = n ∧ n ≠ 1 ∧ n ≠ 2 ∧ n ≠ 4` |
| `TM.WeakCollatz.halts_iff_counter` | `Counter` (a cycle of the shortcut map through some `n ≥ 3`) |
| `TM3.WeakCollatz.halts_iff` (3 symbols, `Core/Basic3.lean`) | the same statement as `TM.WeakCollatz` |
| `TM.Fermat.halts_iff`, `M90` | `∃ E x y z, 3 ≤ E ∧ 1 ≤ x ∧ 1 ≤ y ∧ 1 ≤ z ∧ x ^ E + y ^ E = z ^ E` |
| `TM.FermatPrimes.halts_iff`, `M25` | `∃ n, 5 ≤ n ∧ Prime (2 ^ 2 ^ n + 1)` |
| `TM.OddPerfect.halts_iff`, `M37` | `∃ n, n % 2 = 1 ∧ properDivSum n = n` |
| `TM.Kurepa.halts_iff`, `M38` | `∃ p, Prime p ∧ 2 < p ∧ p ∣ leftFact p` |
| `TM.Sierpinski.halts_iff`, `M60` | `∀ k, k % 2 = 1 → k < 78557 → ∃ n, 1 ≤ n ∧ Prime (k * 2 ^ n + 1)` (Σ₁: the machine halts iff it is true) |
| `TM.Riesel.halts_iff`, `M76` | `∀ k, k % 2 = 1 → k < 509203 → ∃ n, 1 ≤ n ∧ Prime (k * 2 ^ n - 1)` (Σ₁ likewise) |

Beeping machines (`Core/Beep.lean`): the beep transition is `qb` reading `bb`.

| Theorem | Statement |
|---------|-----------|
| `TM.FermatPrimesInf.quasihalts_iff`, `M16` | `QuasiHalts delta G0 false start ↔ ¬ InfinitelyManyFermatPrimes`, with `InfinitelyManyFermatPrimes := ∀ n, ∃ k, n ≤ k ∧ Prime (2 ^ 2 ^ k + 1)`; also `never_halts : ¬ Halts delta start` (and for `M16`: `delta2`, `St2.G0`, `start2`) |
| `TM.TwinPrimes.quasihalts_iff`, `M18` | `QuasiHalts delta G2 false start ↔ ¬ TwinPrimeConjecture`, with `TwinPrimeConjecture := ∀ n, ∃ p, n ≤ p ∧ Prime p ∧ Prime (p + 2)`; also `never_halts : ¬ Halts delta start` (and for `M18`: `delta2`, `St2.G2`, `start2`) |
| `TMK.TwinPrimes4.quasihalts_iff` (4 symbols, `Core/Multi.lean`, `Core/BeepK.lean`) | `QuasiHalts delta St.beep 0 start ↔ ¬ TwinPrimeConjecture`; also `never_halts` and `beeps_forever_iff` |

The PA machines (`TinyCryptids/PA`, compiled by TMBuilder, whose `Machine.lean` is the compiled

|---------|-----------|

| `TMK.PA.halts_iff`, `M10` (`TinyCryptids/PAK`, 10 symbols, `TMK.Halts`) | the same: `Wff.Provable (Wff.el 0 0)` |

| Theorem | Statement |
|---------|-----------|
| `TM.ABC.repeats_iff`, `M235` | `RepeatsForever delta xe3 false xq6 false start ↔ ¬ ABCConjecture`, with `ABCConjecture := ∀ n, 1 ≤ n → ∃ N, ∀ a b, 1 ≤ a → 1 ≤ b → Nat.gcd a b = 1 → N ≤ a + b → (a + b) ^ n ≤ rad (a * b * (a + b)) ^ (n + 1)`; also `never_halts : ¬ Halts delta start` (and for `M235`: `delta2`, `St2.xe3`, `St2.xq6`, `start2`) |

## Proof outlines

**Weak Collatz** (`TinyCryptids/WeakCollatz`), the 14-state machine. One block with the
value `v` as a hole at cell `v − 1` (`CS M v`), iterating the shortcut map `tc`. `Step`: going
home (`go_home`), `v = 1` (`step_one`), the halving loop (`HL`: a marker from cell 0 meets the
hole; for even `v` the marker is the result, `hl_even`, `step_even`), the odd loop (`OL`: the
marker walks back while the hole moves two cells, `hl_odd`, `ol_over`, `ol_end`, `step_odd`),
`step_cases` and `round_run`. `Spec`: rounds stop when no nontrivial cycle lies below `n`
(`reach_cond`, by induction on `n`), do not return to `n` without a cycle (`round_no_return`),
and a cycle gives a least `M` whose round halts (`exists_top`). `Cycle`: `tc`-cycles through
`n ≥ 3` are exactly `collatz`-cycles outside `{1, 2, 4}` (`counter_iff`).
`TinyCryptids/WeakCollatz16` is the same proof for the given 16-state machine (marker from
cell 1, `cut` and `grow`), sharing `Spec` and `Cycle`. `TinyCryptids/WeakCollatzV1` is the
earlier 25/23-state machine: parity walk, `EL`/`OL` loops, the same `Spec` for `collatz`.
`TinyCryptids/WeakCollatz3` is the 10-state, 3-symbol machine (`TM3`: `Core/Basic3.lean`, the
model of `Core/Basic.lean` with symbols `s0 s1 s2`). The end of the block is a 2 that is also
the hole of `v = M` (`RS`, `HE`, `OE`); `ol_run` sorts the odd loop's outcomes. It shares
`WeakCollatz/Spec` and `Cycle`.

**Fermat** (`TinyCryptids/Fermat`), the 127-state design and the 90-state merged machine.
`Copy`: the copy loop with a cursor of its own on R (R's hole is the single 0 after A; Q after
another single 0). `Blk`, `Pow`: power computation R := base^E with the base block marked by a
hole on its cell 1, a round that starts without a base hole, cursors allowed next to a
separator (`ParserL.find3`, `lg_find`), and the merge entered from the end of the base.
`NextBase`: the marker moves to the next base and R is added into A by filling the 0 between
them; a new `R = 1` is cut from the end. `Compare`: the zig-zag (`zz`, halt iff A has one cell
more than R) and `HaltAt`. `Tuple`: the setup (the next-base step from the anchor,
`ParserR.find3`), one tuple (`tuple_check`), the clear. `Enum`: one enumeration step.
`Nexcom`: the search order `nxt` (NEXCOM on compositions) reaches every valid tuple. `Main`:
the seed and the main loop; `M90` is generated by `gen_reduced_lean.py`.

**Twin primes** (`TinyCryptids/TwinPrimes`, beeping). Tape `D 0 R`, holes found by scanners that
count zeros. Every routine is proved for `deltaNB` (the design without its beep transition,
generated next to `delta`; `deltaNB_sub`), so its runs never beep; only `beep_step` uses
`delta`. `Round`: `W d r c k` (the mod walk with `k` steps left), `walk_core`, `walk_step`,
`walk` (D's hole ends on `(c + k) % d`), `check_fail` / `check_ok` (D's cells `d − 1, d − 2,
d − 3`), `shift_more` / `shift_beep` (`d + 1`, `r − 1`; R empty: `BeepCfg`), `rebuild`, `seed`.
`Spec`: `Good`, `fail_iff` (the hole on `d − 1` or `d − 3` iff `d ∣ m ∨ d ∣ m + 2`), `twin_iff`.
`Main`: `test` (induction on `r`), `cand_twin`, `cand_not`, `after_beep`, `cand_step`,
`reach_cs`; (→) a twin prime `p ≥ N + 3` beeps after step `N`; (←) `deltaNB` never halts from
`CS (N + 3)` (`not_halts_of_progress`), so `quasihalts_of_sub`. `M18` by
`quasihalts_iff_of_sim` with `excl`.
`TinyCryptids/TwinPrimes4` is the 10-state, 4-symbol machine (`TMK`, `Core/Multi.lean`; beeps
in `Core/BeepK.lean`). Tape `D R` with D's cells 3, R's cells 1 and a marker / cursor 2, so there
is no separator. `Round`: `walk_step`, `walk`, `zig` and `rebuild` (`reb`'s zigzag), `check_fail`,
`check_ok`, `zs_beep`, `start_beep`, `beep_step`, `after_beep` (the beep path makes candidate
`m + 3`). `Main`: `test`, `cand_twin`, `cand_not` (sharing `TwinPrimes/Spec`), `reach_cand`
(every `m ≥ 3` is a candidate or follows a twin prime candidate by 1 or 2), `twin_gap` (lesser
twin primes `q < p < q + 3` are 3 and 5) and `reach_twin`, then (→) and (←) as above.

**Fermat primes** (`TinyCryptids/FermatPrimes`). `../twinprimes`'s walk with odd `d` and odd
`m`, testing `m` and `m − 1`, halting. `Spec`: `odd_not_dvd_pow2`, `pow2_of_no_odd`,
`dvd_pow_odd_add_one`, `prime_pow_two_add_one` (`2^k + 1` prime ⟹ `k` a power of
2), `fp_iff'`, `prime_of_lt` and `prime_17`, `prime_257`, `prime_65537` (by `decide`), `fp_small`
(the passes in `[7, 65537]`), `fp_big_iff`. `Round`: the walk for any tail `F ::: Y`,
`check_last`, `check_first`, `check_ok`, `shift`, `rebuild`, `PassCfg`, `pass_more`, `pass_halt`,
`seed`. `Main`: `CS m g j` (the counter `j` cells away), `fail_iff`, `test`, `cand_pass`,
`cand_not`, `fails`, `reach_big` (5, 17, 257, 65537 leave one cell), `haltAt_of`; (→) by
`not_halts_of_progress` from `CS 65539`, (←) by `haltAt_of`.

**Fermat primes, infinitely many** (`TinyCryptids/FermatPrimesInf`, beeping). `../fermatprimes`'s
machine without the counter: every pass beeps. `Spec`: `fpi_iff` (the passes are unbounded iff
`InfinitelyManyFermatPrimes`); `Good`, `FP`, `fp_iff'` and `fail_iff` are imported from `FermatPrimes`.
`Round`: `W`, `walk_all`, `walk_end`, `shift`, `rebuild`, `beep_step`, `seed`, with
`../fermatprimes`'s `check_last`, `check_first` (joined in `check_fail`) and `check_ok`. `Main`:
`test`, `cand_fp`, `cand_not`, `after_beep`, `cand_step`, `reach_cs`, `never_halts`, `quasihalts_iff`,
`beeps_forever_iff`, as for Twin primes. `M16` by `quasihalts_iff_of_sim` with `excl`.

(→) by `not_halts_of_progress` over the round starts (each round strictly reaches the
next when there is no counterexample); (←) by iterating the round up to the
counterexample, which reaches the explicit halting state.

**Sierpiński** (`TinyCryptids/Sierpinski`). For `k = 3, 5, …` the machine tests `k·2^n + 1`,
`n = 1, 2, …`, and halts when a counter of the `k` still to come runs out. `Round`: the mod walk
with the D hole's home on D's last cell (`MW`, `dadv`, `mw_step`, `mw_upto`, `mw_last`; parsers
meeting a hole next to a separator: `PPR.find3`, `PPM.find3`), then on the way back the divisor
test: `comp_start` (home: composite), `shift` (to `d + 1` without a reset) and `prime_end`.
`Cycle`: `test` (trial division from `d = 3`), the rebuild (`comp_end`, `rtail`), the loop with
one-cell separators (`loop_tail`, `loop`, `loop0`), the end of the doubling (`dfin`: the next
candidate is `2P − 1`) and the `wipe` after a prime. `Counter`: four groups of four bits (`grp`,
`Cs`), the decrement from the loop's end or a marker (`Mk`, `grp_dec`, `cnt_dec`) and the halt at
0 (`cnt_zero`); `newk` turns the copy of K into the next region, `newk_pseudo` for the step to
`k = 1`. `Main`: checkpoints `CK k n v` (testing `k·2^n + 1`) and `KT k v` (the step to `k`),
`cand`, `kt_next`, `kt_pseudo`, `kt_halt`, the `search` over `n`, `reach_i` over `k`; (→) by
`bad_loops` (a `k` without a prime never leaves `CK k n v`), (←) by `reach_i` up to the counter's 0.

**Odd perfect numbers** (`TinyCryptids/OddPerfect`). `RN n` is the end of the round for
`n` (T holding `min (properDivSum n) (n + 1)`). `walk` (`../Sierpinski`'s mod walk, D's home
on its last cell): the D hole ends home iff `d ∣ n`; then `add` walks it down to cell 0,
advancing the T counter by `d` (saturating at `n + 1`: `add_unit`); `shift` moves the
separator. `dloop`: over `d = 1 .. n−1` the counter becomes `min (properDivSum n) (n + 1)`.
`round_end` (`re_fill`, `check`, `reset`): halt iff the counter is `n`; otherwise the round for
`n + 2` starts. `seed_reach`: a pseudo-round `n = −1` reaches `RN 1`.

**Kurepa** (`TinyCryptids/Kurepa`). `Spec`: `dvd_fact`, `leftFact_mod` (`!(q + k) ≡ !q mod q`),
`exists_prime_dvd`, and `kurepa_iff`: some `n ≥ 3` divides `!n` iff some odd prime `p` divides `!p`
(`!n ≡ 2 mod 4` for `n ≥ 4`). `Round`: `NL m c` (N with its hole at `c`), the test `TP m c lam K j`,
one unit (`unit_step`, `unit_wrap`, `nx`), its end `TE` (`te_halt`, `te_grow`), the copy loop `X`
(`pg_to_x`, `copy_one`, `copy_last`, `c_next`, `c_fall`) and `merge`. `Main`: `test_run`, `nxs_m_eq`
(the N hole is back at cell `m` after `u` steps iff `m ∣ u`), `copies`, `multiply`, `round` for
`RS n`, `seed_reach`; (→) by `not_halts_of_progress`, (←) by `haltAt_of`.

**Riesel** (`TinyCryptids/Riesel`). The proof of an earlier 110-state Sierpiński design (a copy loop
with two-cell separators, trial division from `d = 3`) with `k·2^n − 1`: the rebuild keeps all
cells (`comp_end`), so the next candidate is `2P + 1` (`cand_succ`); the counter has five groups,
with its lemmas proven for any number of groups (`Cg`, `cg_dec`, `cg_zero`); the search starts
at `k = 5` (`good_one`, `good_three` for `k = 1, 3`).

**abc conjecture** (`TinyCryptids/ABC`, beeping booping). `Mult`: the multiplication `Z := Z · base`
proved once on a template machine (`mult`), embedded as `multR` and, mirrored, as `multL`
(`Core/Mirror.lean`). `Gcd`: `gcd_run`, by the coprimality walk (`Walk`: `first_hit`). `Factor`, `Round`: the
tests `pass_A/B/C`, `hit_A/B/C`, `new_R`, `notnew_R`, `next_d`, `last_d`. `PairEnd`: `pe_erase`,
`next_ab`, `next_c`, `wr_go`, `hitA_nc`, `hitB_nc`. `Compare`: `compare`. `Power`: `pre_entry`,
`pre_skip`, `pre_pass`, `q_mult`, `loop_beep`, `loop_boop`, `beep_step`, `boop_end`. `Spec`:
`rstep_rad`, `rfrom_rad` (`R = rad(abc)`), `gcd_ac`, `val_spec`, `pairAt_spec`, `pairAt_onto`,
`good_iff`. `Main`: `factor_loop`, `power` (a `Trace`), `pair_trace`, `seed`, `Tm`, `never_halts`,
`repeats_iff` by `repeatsForever_of_segments`. `M235` by `repeatsForever_iff_of_sim` with
`excl_beep` and `excl_boop`.

**PA** (`TinyCryptids/PA`, see `../pa/PROOF.md`). `Machine.lean`: the machine TMBuilder compiles
from any decision DAG; `M309.lean` checks the 309-state table is that machine for the program's
DAG. `Sem.lean`: big-step semantics of DAG nodes (`Ex`: break and continue outcomes, restarts).
`Tape.lean`, `Frame.lean`: the register file, both phases of a register operation, dispatch
(`DOK`), the walk, cleanup, and `sim` (by induction on `Ex`, for any DAG meeting `DagOK`;
`DagCheck.lean` checks it). `Prog.lean`, `Nodes.lean` (generated), `Clean.lean`, `Abs.lean`,
`Iter.lean` (generated): every node's effect, the subroutines as stack operations, main as one
iteration (`main_emb`). `Step.lean`, `Search.lean`: one iteration of the proof search (`iter_eq`);
soundness (`cand_sound`, `good_step`), completeness (`axiom_M`, `rpn`, `reach_code`),
`search_iff`. `Luk.lean` (generated by condensed detachment), `Logic.lean`: permutation,
contraposition, `e_swap`. `Boot1.lean`: the 5-state counter in seven rounds of sweeps;
`Boot2.lean`: 1908 inc/decnz pairs build the register file. `Run.lean`, `Main.lean`: `from_main`,
`halts_iff`.

**PA with 10 symbols** (`TinyCryptids/PAK`, see `../pa_nsymbols/PROOF.md`). `Machine.lean`: the
machine `pa_nsymbols/kary.py` compiles from the program tree of `Tree.lean` (generated); `M10.lean`
checks the file's table against it. `Sem.lean`: big-step semantics of the tree (`Run`, from a node's
slot). `Tape.lean`, `Ops.lean`: the register file and the register operations, including the
creation of a register on the blank after the file. `Frame.lean`: dispatch, the walk, `nodeOK`
(by `decide`) and `sim`. `Shape.lean`: running a node's slots (`runS_sound`), loops with a measure;
`Nodes.lean` (generated): every node's denotation. `Abs.lean`, `Comp.lean` (generated): the
subroutines on `TM.PA.A`, main as a chain of operations (`k0_emb`). `Cand.lean` (generated),
`Step.lean`: the candidates in this machine's order and forms, `stepK`, `search_iff`.
`Boot.lean`: the first 853 steps by computation (the register file is created). `Run.lean`:
`pass`, `first_pass`, `halts_iff`.
