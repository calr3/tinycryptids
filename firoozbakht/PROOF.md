# The proof, in plain words

This is a guided tour of the Lean proof that the 117-state machine
`machines/firoozbakht_117.txt` halts if and only if Firoozbakht's conjecture is false. The
hand-written proof is about 1,750 lines in `../lean/TinyCryptids/Firoozbakht/` (`Arith`,
`Blocks`, `Cyc`, `Trial`, `Copy`, `CopyC`, `Horner`, `Compare`, `Prime`, `Main`, and the step
tactics `Tac`); the machine tables `Machine.lean` and `M117.lean` are generated. Each step below
names the lemma that carries it.

## What is proved

```lean
theorem TM.Firoozbakht.halts_iff : Halts delta start ↔
    ∃ p q, Prime p ∧ Prime q ∧ p < q ∧ (∀ r, p < r → r < q → ¬ Prime r) ∧
      p ^ (primeCount p + 1) ≤ q ^ primeCount p

theorem TM.Firoozbakht.M117.halts_iff : Halts M117.delta2 M117.start2 ↔ (the same)
```

* `Prime p` is "`2 ≤ p` and no `d` with `2 ≤ d < p` divides `p`", `primeCount x` the number of
  primes `≤ x` (`TinyCryptids`, `../lean/TinyCryptids/Defs.lean`). `p < q` prime with no prime between makes
  `q` the prime after `p`; with `n = primeCount p`, `p` is the `n`-th prime, and
  `p^(n+1) ≤ q^n` is the negation of Firoozbakht's `q^n < p^(n+1)`.
* `delta` is the 166-state design `firoozbakht.txt` (generated by `build.py`, transcribed by
  `gen_lean.py` into `Machine.lean`), `start` its first state on a blank tape. `delta2` is the
  117-state machine (`M117.lean`), `start2` likewise.
* `Halts δ c`: started in `c`, the machine reaches a configuration with no transition
  (`../lean/TinyCryptids/Core/Basic.lean`, the model shared by every machine in the repository).

Both theorems depend only on `propext`, `Classical.choice` and `Quot.sound`
(`../lean/Check.lean` prints this).

## The idea

    list := [2]; N := 3                                 (N = length of the list + 2)
    for m = 3, 4, 5, …:
      if no prime of the list divides m:                (trial division)
        p := the last prime of the list; k := its length
        if p^(k+1) ≤ m^k: HALT
        add m to the list; N := N + 1

Everything is unary. A block holding `v` has `v + 2` cells, and a **cyclic hole** in cells
`1 … v` serves as a pointer. **CYC(counter, cycled)** decides divisibility (the cycled hole
goes round once, the counter hole advances before each of its steps); a **power run** builds
`b^(e − ep)` by rounds `R := b·R`, with an exponent hole counting rounds and a base hole
counting copies of R. Both power runs use the one exponent block N; the second run starts its
exponent hole two cells later.

## Part 1: the primes (`Arith.lean`, `Main.lean`)

**Lemma 1 (`pl`, `mem_pl`, `prime_iff_pl`).** `pl m` is the increasing list of primes below
`m`; `m ≥ 2` is prime iff no element of `pl m` divides it (a least divisor `≥ 2` is prime,
`exists_prime_dvd`). These come from `../feitthompson`.

**Lemma 2 (`primeCount_pl`, `pl_filter`).** `primeCount x = (pl (x + 1)).length`.

**Lemma 3 (`pl_last`, `pl_between`).** If `pl m = pre ++ [p]`, then `p` is prime, `p < m`, and no
prime lies strictly between `p` and `m`. Conversely, if no prime lies strictly between the prime
`p` and `q`, then `pl q = pl p ++ [p]`. Hence (**`bad_iff`**) at a prime `m` with
`pl m = pre ++ [p]`, the machine's test `p^(|pl m| + 1) ≤ m^|pl m|` is exactly the statement's
`p^(primeCount p + 1) ≤ m^(primeCount p)`.

## Part 2: tapes and blocks (`Blocks.lean`, `Trial.lean`)

`Blk`, `Gap`, `Clean` describe stretches of hole-free blocks with `00` separators, which the
2-state parsers cross (`ParserR.find`, `ParserL.find` in `Core/Lemmas.lean`). `skp v` is a
block with its hole at cell 1, `seps ps` the blocks of a list, each after a `00`. The tape of
the candidate `m` is `N 00 P1 … 00 Pk 00 M` with `N = skp e`, `M = skp m`; `lft e pre` is the
part left of a list block.

## Part 3: divisibility (`Cyc.lean`)

**Lemma 4 (`nxs_dvd`).** A cyclic hole with positions `1 … c`, advanced `v` times from cell 1,
is back at cell 1 iff `c ∣ v` (`nxs_mod`: from `n % c + 1`, `k` advances lead to
`(n + k) % c + 1`).

**Lemma 5 (`cyc_run`).** With the counter (value `c`) left of the cycled block (value `v`),
from `cyc2` (the counter's hole just advanced from cell 1) the machine reaches the counter's
right end, the counter's hole filled, the cycled hole back at cell 1, in state `PM1` if `c ∣ v`
and `kn3` otherwise. *Proof:* one step is `ctr_adv` (the counter hole advances, `ctr_nowrap`
or `ctr_wrap`) and `pc_part` (to the cycled hole, advance it, back); the last is `pc_last`
(the cycled hole wraps; `k1 … k3` read whether the counter hole is at cell 1). Induction on the
remaining steps (`cyc_loop`), then Lemma 4. This is Feit–Thompson's `CYC` with the parsers
mirrored.

## Part 4: the trial pass (`Trial.lean`)

`TC e m pre p post` is the trial step of the list block `p` (`pre ++ p :: post = pl m`): state
`kn6` on cell 1 of that block.

**Lemma 6 (`trial_cyc`).** From `TC` the machine runs `CYC(p, M)` (Lemma 5).

**Lemma 7.** After it: if `p ∣ m`, `trial_div` goes to M's hole (`MS`), `ms_end` to the cell
after M, and `next_cand` makes M one longer, goes back left to N's hole (`PX`, `PY`) and across
N to the trial step of `P1` for `m + 1`. If `p ∤ m` and another block follows, `trial_next`
reaches its trial step. If `p ∤ m` and M follows, `m` is prime: `trial_prime` (with `retreat`)
puts the marker back on `p` (`PR`).

## Part 5: the prime path (`CopyC.lean`, `Horner.lean`, `Prime.lean`)

**Lemma 8 (`prime_copy`).** From `PR`, a walk to the right end writes `11` after a `00`, the copy
loop (`copyC_all`, the copy loop of `../fermat` with its own states) appends `m` cells, M is
left without a hole (it is now the list block `q`), and a hole at cell 1 makes the new block
`M' = skp m`.

**Lemma 9 (`horner`, with `exp_round`, `base_loop`, `base_wrap`).** One round of a power run,
from the exponent hole at cell `ep < e`: the base hole goes round (`base_adv`: `β − 1` copies of
R onto Q, `copy_full`, `nb_back`), then `base_wrap` merges `R 00 Q` into `R + Q` (two cells
erased), so `R := β·R`; the exponent hole moves one cell. By induction (`exp_loop`, `hrn_pow`),
from `R = 1` the run ends with `R = β^(e − ep)`, the exponent hole back at cell 1, head on the
exponent's cell 2, state `PD1` (`exp_wrap`). `he_chain` finds the holes going left from R: R's
cursor, the skipped hole, the base, the exponent. `hrun` packs walk, push and run.

**Lemma 10 (`run_b`, `after_b`, `run_a`, `after_a`).** `H_B` (skipped M', base `p`, exponent N
with hole at cell 1): `B = p^(e − 1)`. Then `after_b`: the first hole right of N is `p`'s marker,
and the block after it (the list block `q`) has a 1 at cell 1 (`dk4`), so the machine goes back
to fill the marker (`QA`, `qf`), on to N (`QB`), writes a new cell 0 for N and moves N's hole to
the new cell 3 (`n1 … n4`). `H_A` (skipped B, base M', exponent N of value `e + 1`, hole at
cell 3): `A = q^(e − 2)`. Then `after_a`: the first hole right of N is now M''s, and the block
after it is B, whose cell 1 is its hole: on to the comparison (`z0`).

## Part 6: the comparison (`Compare.lean`)

**Lemma 11 (`compare`).** From `z0` on B's cell 2, with `B = 1 0 1^b`, `A = 1 0 1^a`
(`a, b ≥ 1`): if `b ≤ a` the machine halts; if `a < b` it erases A and B and stops on the
separator after M' in state `ms`. *Proof:* `ZC x g y` is the zig-zag state (B with `x` units,
`g` blanks, A with `y`). `zc_step`: one cell off each, `ZC (x+2) g (y+2) → ZC (x+1) (g+1) (y+1)`;
`zc_halt`: B's last unit erased, HALT; `zc_clean`: A's last unit erased, clean up. Induction on
`y` (`zc_run`).

**Lemma 12 (`prime_step`).** Lemmas 8, 10, 11 composed: from the end of the trial pass of a
prime `m` with the list `pre ++ [p]` and `N = skp e`, the machine halts if
`p^(e − 1) ≤ m^(e − 2)`; otherwise it reaches `MSE (e + 1) m (pre ++ [p, m])`, the cell after
the new M, with `m` in the list and N one longer.

## Part 7: the main theorem (`Main.lean`)

The checkpoints are `TC (|pl m| + 2) m pre p post` with `GT` (`3 ≤ m`, `pre ++ p :: post = pl m`,
no element of `pre` divides `m`). `TS m` is the first, at `P1 = 2`.

**Lemma 13 (`trial_step`).** From a checkpoint: if `p ∣ m`, `m` is not prime and the machine
reaches `TS (m + 1)`; if `p ∤ m` and a block follows, the next checkpoint; if `p ∤ m` and `p`
is the last block, `m` is prime (Lemma 1), and the machine halts if `Bad m pre p`
(`p^(|pl m| + 1) ≤ m^|pl m|`) and reaches `TS (m + 1)` otherwise (Lemma 12; `pl (m + 1) =
pl m ++ [m]`, so `N` is right for `m + 1`).

**Lemma 14 (`start_reach`).** The seed writes `N = 3`, `P1 = 2`, `M = 2` and ends after M
(`seed_reach`), and `next_cand` reaches `TS 3`.

**(→) (`not_halts`).** Without a counterexample, `Bad` never holds at a prime (`bad_iff`,
`pl_last`), so every checkpoint reaches a later one in at least one step (`progress`), and
`not_halts_of_progress` shows the machine never halts.

**(←) (`haltAt_of`).** Given consecutive primes `p < q` with `p^(n+1) ≤ q^n`: `pl q = pl p ++
[p]` (`pl_between`), so `Bad q` holds for the last block. From every `TS m` with `m ≤ q` the
machine reaches `TS (m + 1)` or halts (`pass_trial`, induction on the list), and at `m = q` it
halts.

**The merged machine (`M117.lean`).** `minimize.py` merges only states that agree wherever both
are defined, so the 117-state machine follows the design's run step for step: `compat` checks
every transition (`cases q <;> cases b`), and `halts_iff_of_sim` transfers the theorem.
