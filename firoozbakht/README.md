# A Turing machine for Firoozbakht's conjecture

**Current best: `machines/firoozbakht_117.txt`, a 117-state, 2-symbol Turing machine**
(named-state format, as in `../fermat`). Started on a blank tape, it **halts iff Firoozbakht's
conjecture is false**: iff there are consecutive primes `p < q` with `p^(n+1) ≤ q^n`, where
`n = π(p)` (`p` is the `n`-th prime). Lean proves this (`TM.Firoozbakht.M117.halts_iff`):

    Halts M117.delta2 M117.start2 ↔ ∃ p q, Prime p ∧ Prime q ∧ p < q ∧
      (∀ r, p < r → r < q → ¬ Prime r) ∧ p ^ (primeCount p + 1) ≤ q ^ primeCount p

with `Prime` and `primeCount` (the number of primes `≤ x`) from `../lean/TinyCryptids/Defs.lean`. Firoozbakht's conjecture says that `p_n^(1/n)` is strictly decreasing, i.e.
`q^n < p^(n+1)` for consecutive primes `p = p_n < q = p_(n+1)`; the statement above is its
negation. `RECORDS.md` lists every machine with its state count and Lean theorem. `PROOF.md`
walks through the proof in plain words.

The 117-state machine is obtained in two stages:

1. `firoozbakht.txt` is the readable **166-state design**, generated by `build.py`.
   The Lean proof is written for this machine (`TM.Firoozbakht.halts_iff`).
2. `minimize.py` merges states of the design that never disagree on a transition the run
   uses (an exact SAT search; 117 found, 116 not decided). `gen_reduced_lean.py` carries the
   theorem over. `machines/firoozbakht_117_annotated.txt` is the same machine with each
   state named after its roles in the design, every transition commented.

## The search

The machine tests every candidate `m = 3, 4, 5, …` for primality by trial division by the primes
found so far, which the tape keeps as a list. When `m = q` is prime, the last list entry is the
previous prime `p` and the list length is `n = π(p)`; the machine computes `B = p^(n+1)` and
`A = q^n` in unary and halts iff `B ≤ A`. Then `q` joins the list. It never has to search for
"the next prime", so the proof does not need infinitely many primes.

## How it works

A number `v` is a block of `v + 2` ones; its cells `1 … v` are the positions of a
**cyclic hole** (a single 0) that advances one cell right and wraps from cell `v` to cell 1.
Tape layout:

    N 00 P1 00 P2 00 … 00 Pk 00 M [00 M' 00 B [00 A]]

* **N** holds `k + 2` (`k` = the number of primes below `m`); its hole is at cell 1 at rest. It
  is the exponent of both power runs.
* **P1 < … < Pk** are the primes below `m`. They are full except the **marker** (a hole at
  cell 1) of the block being visited.
* **M** holds the candidate `m`, with a hole (at cell 1 at rest).

**CYC(counter, cycled)**, the divisibility test (the routine of `../feitthompson`, mirrored: the
counter is on the left): the cycled block's hole goes round once (`v` steps); before each step
the counter's hole advances. It is back at cell 1 iff the counter divides `v`.

Candidate `m`:

* **Trial pass**, left to right: `CYC(Pi, M)` for `i = 1 … k`. If `Pi ∣ m`, `m` is composite:
  `M += 1` (a cell on its right), back to N, the marker on P1. Otherwise the marker moves
  right; reaching M (its cell 1 is a hole), `m` is prime.
* **Prime `m = q`** (`p = Pk`, `n = k`):
  * the marker goes back to Pk; M is copied to a new block **M'** right of it (`11`, then a copy
    loop, then a hole at cell 1), and M, without its hole, joins the list as `P(k+1) = q`;
  * **power run `H_B`**: `R = 101` (it holds 1) is pushed at the right end; going left from
    it the run finds a skipped hole (M'), the base (Pk's marker) and the exponent (N's hole). Each
    advance of the exponent hole is a round `R := b·R`: as the base hole goes round, `b − 1`
    copies of R are appended after a `00`, then the `00` is filled and two cells are erased.
    N's hole starts at cell 1, so there are `k + 1` rounds: `B = p^(k+1)`;
  * Pk's marker is filled; N grows by one cell on its left and its hole moves to (new) cell 3;
  * **power run `H_A`**: skipped B, base M', exponent N, with `(k + 3) − 3 = k` rounds:
    `A = q^k`. N's hole is back at cell 1: N holds `k + 3`, right for the next prime;
  * which run just ended is read off the block after the first hole right of N: `P(k+1)` (its
    cell 1 is a 1) after `H_B`, B (its cell 1 is B's hole) after `H_A`;
  * **compare**: the last cell of B is erased, then the last cell of A, in turn. If B is used up
    first, `B ≤ A`: the machine **halts**. Otherwise the rest of A and B is erased, the
    separator after M' is filled (`M' += 1`) and M' is the next candidate's M.

The seed writes `N = 3`, `P1 = 2`, `M = 2` and enters "`M += 1`": the trial pass of `m = 3`.

State budget of the 166-state design: seed 17, CYC 27, next candidate 8, retreat and copy 26,
push 5, power run 54, which-run and the step after `H_B` 15, compare and clean up 16.

## Files and checks

* `build.py` generates the design (`python3 build.py firoozbakht.txt`).
  `build(variant=1)` starts N one larger, so the test is `p^(n+2) ≤ q^(n+1)`, which holds for
  `(2, 3)` (`8 ≤ 9`): it halts after 1,718 steps.
* Shared tools in `../tools/`: `tm.py` parses the format and converts it to bbchallenge
  standard text (`python3 ../tools/tm.py machines/firoozbakht_117.txt`); `sim.c` is a fast
  simulator; `same_run.py A B k` checks that two machines have identical tapes after
  10^3 .. 10^k steps; `minimize.py` (exact SAT) and `greedy_merge.py` merge states.
* `ref.py`: for each prime `q`, the values `(p, q, n, B, A)` the machine computes.
* `test_routines.py`: routines on hand-placed tapes: the trial pass for `m = 3 … 79` (prime or
  composite), the prime path for `q = 3, 5, 7, 11` (the tape after `H_B` and after `H_A`), the
  comparison for `a, b ≤ 11`.
* `test_e2e.py`: after each power run of the real machine (state `dk4`) the tape is
  `N 00 P1 … 00 M' 00 B [00 A]` with the values of `ref.py`; the variant halts at `(2, 3)`; the
  real machine runs past 10⁸ steps. (Unary powers grow fast: `(7, 11)`, with
  `B = 7⁵ = 16,807`, is reached after about 2·10¹⁰ steps.)
* `gen_lean.py` writes `../lean/TinyCryptids/Firoozbakht/Machine.lean` (the design);
  `gen_reduced_lean.py machines/firoozbakht_117.txt M117` writes `M117.lean`;
  `annotate.py machines/firoozbakht_117.txt machines/firoozbakht_117_annotated.txt M117`:
  the readable listing.
* The proof: `../lean/TinyCryptids/Firoozbakht/` (see `../lean/README.md` and `PROOF.md`).
