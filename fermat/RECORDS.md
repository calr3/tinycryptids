# Best machines so far

All machines are 2-symbol, start on a blank tape, and halt iff
`x^E + y^E = z^E` has a solution with `E >= 3`, `x, y, z >= 1`.

| States | File | How obtained | Status |
|-------:|------|--------------|--------|
| **90** | `machines/fermat_90.txt` (readable: `fermat_90_annotated.txt`) | `minimize.py` with `MIN_SOLVER=kissat404` on the 127-state design (cadical195 reached 91; neither found 89 before the searches were stopped) | Proven in Lean: `TM.Fermat.M90.halts_iff` |
| 127 | `machines/fermat_127.txt` (= `fermat.txt`) | `build.py`: R's hole is the single 0 after A (R hole-less, adding R into A in 3 states, A may be empty), a single 0 between R and Q, a copy cursor of its own on R, the merge entered from the end of the base, a 1-state scan back to R's hole, a compare that halts iff R runs out with one cell of A left | Proven in Lean: `TM.Fermat.halts_iff` |

Earlier designs, each proven in Lean when it was current (not kept here): 174 states (the
first design; 123 by a greedy merge), 165 states (merged to 102 by `kissat`), 149 states
(merged to 95). `README.md` describes the steps from one to the next.

How merged machines are proven: `minimize.py` / `greedy_merge.py` only merge states whose
defined transitions agree, so the merged machine follows the same run. `sim_run` and
`halts_iff_of_sim` (`lean/TinyCryptids/Core/Basic.lean`) turns this into a proof: `gen_reduced_lean.py` emits the merged machine,
the state map `phi`, a `compat` check (one case per transition) and the transferred theorem.

Readable version: `machines/fermat_90_annotated.txt` (generated by `annotate.py`) is the
same machine with each state named after the roles it plays in the 127-state
design, a description of each role, and every transition tagged with the role using it.
