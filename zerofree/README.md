# A Turing machine for zero-free powers of 2

**Current best: `machines/zerofree_44.txt`, a 44-state, 2-symbol Turing machine**
(named-state format, see `../tools/tm.py`). Started on a blank tape, it **halts iff some
power 2^n with n > 86 has no decimal digit 0**. 2^86 = 77371252455336267181195264 is
conjectured to be the last power of 2 without a 0. Lean proves this
(`TM.ZeroFree.M44.halts_iff`):

    Halts M44.delta2 M44.start2 ↔
      ∃ n, 86 < n ∧ ∀ k, 2 ^ n / 10 ^ k ≠ 0 → (2 ^ n / 10 ^ k) % 10 ≠ 0

`RECORDS.md` lists the machines, and `PROOF.md` walks through the proof in plain words.

The 44-state machine is obtained in two stages:

1. `zerofree.txt` is the readable **55-state design**, generated by `build.py`. The Lean
   proof is written for this machine (`TM.ZeroFree.halts_iff`).
2. `../tools/minimize.py` merges states of the design that never disagree on a transition
   the run uses (an exact SAT search). `gen_reduced_lean.py` carries the theorem over, and
   `machines/zerofree_44_annotated.txt` is the same machine with each state named after its
   roles in the design.

## The search

    counter := 27
    x := 1                                   (2^0)
    loop:
        if x has no digit 0: counter := counter + 1; if counter = 64: HALT
        x := 2x

The powers 2^n with n ≤ 86 that have no digit 0 are exactly 36 (0–9, 13–16, 18, 19, 24,
25, 27, 28, 31–37, 39, 49, 51, 67, 72, 76, 77, 81, 86). So the counter, which starts at
64 − 37 = 27, overflows exactly at the first such power beyond 2^86. The machine never
compares n with 86: the counter does it.

## How it works

The tape, left to right:

    v5 g5 v4 g4 ... v0 g0 | 0 0 | b x y z | b x y z | ... | blank
    counter                 sep   digit 0   digit 1        (least significant first)

* **Counter.** Six bits `v_i`, each with a guard cell `g_i = 1`, so the counter never
  contains `0 0`. Incrementing walks left over 1 bits (setting them to 0) to the first 0
  bit. If it runs past `v5` into the blank, the counter overflowed and the machine halts.
  A parser then runs right and stops after the separator `0 0`.
* **Digits.** A decimal digit `d = 2a + b` takes four cells: its parity `b`, then `a`
  (0..4) in three cells `x y z`.

Doubling gives digit `d` the new value `2 (d mod 5) + carry`, and passes on the carry
`[d ≥ 5]`. Its parity is the incoming carry, and its `a` becomes `(2a + b) mod 5`, with carry
out `[2a + b ≥ 5]`: doubling a base-5 digit with carry `b`.

**Two codes.** No single 3-cell code for `a` lets that be computed one cell at a time from
left to right; the first cell's output always depends on later cells. Computing it would
cost back-steps, and in a first design (64 states, about 50 after merging) those cost about a
dozen states. Instead the machine uses two codes:
* **Code A** holds the digits between rounds.
* **Code B** is what the doubling pass writes. It writes one cell of B for each cell of A
  it reads, with no back-steps. B depends on the old digit, and it determines the new
  `a' = (2a + b) mod 5`.
* **The scan converts back.** It runs right to left anyway to look for a 0. On the way it
  rewrites each digit from B into A, and that direction is again one cell at a time.

`build.py` has the two codes (`A`, `BETA`). `twocode.py` searches all 3-cell codes and finds
8 such pairs; this pair is one of the two that merged smallest.

**A round:**

1. **Pass** (`C0`/`C1`: the carry, `P*`: reading `x y z`). Least significant digit first,
   four steps right per digit. A blank group ends the number (code A is never `000`). With
   carry 1 it first becomes the digit 1; with carry 0 the scan starts on the top digit.
2. **Scan** (`S*`). Right to left, four steps per digit, rewriting into code A. The digit 0
   is parity 0 with `a' = 0`. The separator shows as `0 0` in the `y z` cells, which no
   code B word has.
3. **No digit 0:** increment the counter (`G`, `I`), return (`R1`, `R2`), and start the next
   pass. **Digit 0 found** (`F*`): rewrite the rest into code A, and start the next pass at
   the separator.

The seed writes the counter 27 and the separator. The first pass then runs with carry 1 on
the empty number, which writes 2^0 = 1.
