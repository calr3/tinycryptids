; ============================================================================
; A 72-state, 2-symbol Turing machine that HALTS IFF BROCARD'S CONJECTURE IS
; FALSE, i.e. iff for some consecutive primes 3 <= p < q fewer than 4 primes
; lie between p^2 and q^2.
; Start on a blank tape in the first state. A transition to `halt` halts.
; Lean proof: lean/TinyCryptids/BrocardPrimes/M72.lean, theorem TM.BrocardPrimes.M72.halts_iff.
; ============================================================================
;
; HOW TO READ THIS FILE
;   The machine is the 108-state design of build.py / brocard_primes.txt with
;   states merged. States are merged only when their defined transitions
;   agree, so each state below plays one or more ROLES of the design (its name
;   joins them). Each transition line is tagged [role] with the role(s) that
;   use it. A '-' line is never used. The seed roles run once at the start and
;   only ever read 0, so most states double as a seed step.
;
;
; TAPE LAYOUT at checkpoint m (after deciding m; blocks of 1s):
;
;      M 00 P_k 00 ... P_j 00 1 00 P_(j-1) 00 ... P_1 000 S 0 1^(c+1)
;
;   M      1^(m+2), a plain counter.
;   P_i    one block per prime p <= m, largest first: a 1, a region of p
;          cells holding one HOLE (a single 0), a 1. The hole sits at region
;          index p-1-(m mod p): it moves one cell LEFT per step and wraps from
;          index 0 to index p-1 exactly when p divides the new m.
;   00100  the MARKER, right of the block of q, the smallest prime with
;          q^2 > m (for m < 9: right of the block of 3). Parsers cross it like
;          a separator.
;   S      the square counter: a region of 2n+1 cells (n = isqrt m), hole at
;          index 2n-(m-n^2). It wraps exactly when the new m is (n+1)^2.
;   1^(c+1)  the counter K: c = number of primes found since the last prime
;          square p^2 (p >= 3; before 9 every prime counts).
;
; ALGORITHM (one round per m, starting from m = 2)
;   home      go left to the left end (four 0s) and add a 1 to M.
;   sweep     scan right; at every hole move it one cell left (or wrap it).
;             Two copies: "prime so far" and "composite". The 000 ends it.
;   prime     move S's hole (it cannot wrap), append a 1 to K, go home and
;             copy M to its left: old M becomes the block of the new prime.
;   composite move S's hole. If it wraps, m+1 = (n+1)^2: S grows by 2 (K moves
;             2 cells right), and a scan left finds the marker. If the block
;             left of it has its hole at the last index, n+1 = q is prime: a
;             prime square. Then the block of q moves 3 cells right (the
;             marker passes it), and at the right end K is erased from the
;             right but for its first cell: fewer than 5 cells -> HALT.
; ============================================================================
